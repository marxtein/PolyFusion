日期：2026-06-11
前提：保持 0D（单点功率账 + 解析几何，毫秒级求解，POPCON 可扫描）。
目标：五个位形全部达到 **"工程堆初筛"** 水准——能回答"这个位形按这组假设建堆，电站账能不能闭合、卡在哪条工程红线上、最敏感的假设是哪个"，而不只是"等离子体物理账能不能闭合"。
参照系：PROCESS（UKAEA）、cfspopcon（CFS）、Realta Hammir POPCON（arXiv:2411.06644）、D-T 悬浮偶极电站研究（arXiv:2602.20564）——全部在 `E:\work\digitalfusion-compare\` 可逐式核对。

## 0. 核心判断：差距不在物理精度，在"四个闭环 + 一条不确定度带"

当前平台（审核后状态）：物理功率账闭合、输入域防护完备、文献锚点齐全。
但它回答的问题是 **"给定 τE 等假设，等离子体能不能烧"**。
工程堆初筛要回答的是 **"电站能不能赚出净电，哪条工程约束先卡死"**。

中间隔着四个闭环：

```text
闭环一：电站功率流   Q_phys 高 ≠ 发电。再循环功率（加热墙插效率、低温、泵）
                    可能吃掉一切。必须算到 P_net_e 和 Q_eng。
闭环二：τE 预测模式  τE 是输入 → 初筛结论是循环论证。必须支持
                    "输入 H 因子上限，定标律反解 τE" 的隐式模式。
闭环三：灰分自洽     fHe 是输入 → 稳态堆的氦浓度其实由 τ_He*/τE 决定，
                    输入低 fHe = 偷偷假设排灰完美。
闭环四：工程几何链   B0 不是自由参数——它由"线圈最大场 × 中子屏蔽厚度 ×
                    应力极限"通过几何决定。壁负载、包层、排热同理。
不确定度带：        每条经验定标给 ±带，输出悲观/名义/乐观三套结果。
                    初筛的可信度不来自单点精度，来自"敏感性排序是对的"。
```

这四个闭环里，**一、三、四是五位形共享的新模块**，二是求解器改造，
位形专属的部分（电流驱动、端塞、脉冲循环、悬浮线圈屏蔽）叠在上面。
所以路线是"先建共享工程层，再逐位形挂专属件"——和当年 ConfigSpec 抽象同一打法。

## 1. 共享工程层（新模块，五位形通用）

### 1.1 电站功率流模块 `plant.py`（闭环一，最高优先级）

0D 完全装得下，PROCESS 的对应部分本质也是代数：

```text
热功率：    P_th_total = M_b·P_n + f_cap·(P_rad + P_charged损失沉积到壁/偏滤器)
            M_b = 包层中子能量倍增（D-T 含 Li 放热反应 ≈ 1.1–1.27；无中子燃料 = 0）
电功率：    P_gross = η_th · P_th_total          η_th = 热力循环效率 0.33–0.45（输入档位）
直接转换：  P_DEC = η_DEC · P_charged_escaping    （磁镜端损/先进燃料带电产物，η_DEC 0.5–0.7）
再循环：    P_recirc = P_heat/η_wp + P_cryo + P_pump + P_控制
            η_wp = 加热系统墙插效率（NBI≈0.3，ECH≈0.4–0.5，RF≈0.5）——最被低估的杀手
净电：      P_net_e = P_gross + P_DEC − P_recirc
工程增益：  Q_eng = (P_gross + P_DEC) / P_recirc
```

新红线（全位形）：`P_net_e > 0`、`f_recirc = P_recirc/P_gross ≤ 0.3`。
**这一层会立刻杀死一批现在看着漂亮的高 Q_phys 点**——比如 Q=5 但加热是 NBI
（η_wp=0.3）的点：Q_eng ≈ 5×0.3×0.4 ≈ 0.6，根本不发电。这正是初筛该干的事。

实现量级：~150 行 + 每位形一个 `plant_map`（声明哪些功率走哪条通道）。
锚点：PROCESS 的 power balance 模块（`process/models/power.py`）逐式核对。

### 1.2 中子学与包层 proxy（闭环四之一）

```text
中子壁负载：  Γ_n = P_n / S_w   红线 Γ_n ≤ 2–4 MW/m²（材料档位输入）
氚增殖：      TBR = c_cov · TBR_local    c_cov = 包层覆盖率（位形几何给：
              托卡马克~0.85，仿星器~0.8，磁镜>0.9，FRC 直筒~0.9，偶极外壁~0.5！）
              红线 TBR ≥ 1.05（仅 D-T）
屏蔽厚度：    Δ_shield = λ_n · ln(Φ_n / Φ_max_coil)   λ_n ≈ 0.08–0.1 m（衰减长度）
              → 进 1.3 的几何链；偶极悬浮线圈是特殊案例（见 5.5）
```

全是代数，~80 行。偶极的 c_cov≈0.5 这一条就是文献里"偶极 D-T 难"的定量来源
（arXiv:2602.20564 正面攻这个问题，可直接对标）。

### 1.3 磁体几何链（闭环四之二：B0 不再自由）

```text
线圈处最大场： B_max = B0 · R0/(R0 − a − g − Δ_blanket − Δ_shield − Δ_coil/2)   （环位形）
               直线位形：B_max = B_throat（磁镜喉部）或 B_e·爬升系数（FRC）
技术档位：     B_max ≤ 13 T（LTS）/ 23 T（HTS，输入档位）
应力 proxy：   σ_hoop ≈ B_max²·R_coil/(2μ0·Δ_structure) ≤ 660 MPa（钢）
低温功率：     P_cryo ≈ f_cryo · 磁体储能 proxy（HTS 20K vs LTS 4K 差一个数量级）
```

这条链把"磁场想设多大设多大"变成"给定线圈技术和屏蔽厚度，B0 有上限"——
托卡马克/仿星器初筛的第一约束。~100 行。
锚点：ARC（B_max=23T→B0=9.2T）、HELIAS-5B（B_max≈12.5T→B0=5.5T）公开数。

### 1.4 τE 预测模式（闭环二，求解器改造）

现状：τE 输入 → H 后验。增加镜像模式：**H 输入（上限红线内）→ τE 反解**。
因为 τ_scaling ∝ P_L^(−0.6~−0.7) 而 P_L 又依赖 τE，是隐式方程——
但单变量、单调，定点迭代 5~10 次收敛（cfspopcon 同款做法）：

```text
τE^(k+1) = H · τ_scaling(P_L(τE^(k)))      收敛判据 |Δτ/τ| < 1e-6
```

各位形的定标：托卡马克 IPB98、仿星器 ISS04（f_ren 限位 [0.7,1.3] 并要求注明出处）、
FRC 已有 LSX（保持预测，加外推倍率标签）、磁镜本来就是预测（Pastukhov/GDT）、
偶极见 5.5。UI 加一个"τE 模式开关：assumed / predicted(H=…)"。
实现：每位形 solver 外包一层 ~40 行迭代器，不动内核。

### 1.5 氦灰自洽（闭环三）

稳态灰分浓度不再输入，由粒子平衡解出：

```text
dn_He/dt = S_fus − n_He/τ_He* = 0  →  f_He = τ_He*/τE · (S_fus·τE/n_e)
τ_He*/τE = ρ_He（输入，文献档位 3–7；托卡马克实验 ~5）
```

与功率账耦合（f_He ↑ → 稀释 + Zeff ↑ → Pfus ↓ → S_fus ↓），又是一个小定点迭代，
和 1.4 套同一个外层循环。**对 D-T 堆点初筛影响巨大**：ρ_He=5 时 ITER 类点
的 f_He 稳态值 ≈ 4–8%，比"随手输 0.04"诚实得多；对 p-B11 类（fion=1）更是生死项。

### 1.6 不确定度带与敏感性输出

每条经验定标挂一个出厂不确定度（IPB98 ±15%，ISS04 ±20%，LSX 外推 ×(0.5–2)，
Pastukhov 域内 ±30%，Sudo ±30%……写死在代码里、文档给出处）。
求解器跑三遍（悲观/名义/乐观）+ 对 8~10 个关键输入做 ±10% 单参数扰动：

```text
新输出：P_net_e ∈ [悲观, 名义, 乐观]
        sensitivity_ranking = [(参数, dlnP_net/dlnx), ...] 排序
```

初筛报告的核心交付从"一个点"变成"一个带 + 一张敏感性排序表"。
0D 快（毫秒级），跑 3+20 遍毫无压力——**这是 0D 相对重型程序的本质优势，要用足**。

### 1.7 运行点寻优器

初筛问题常是反问题："给定几何与技术档位，最大 P_net_e 的运行点在哪？"
在 POPCON 网格上取 argmax + 局部 Nelder-Mead 精修（scipy 不引入也行，手写 50 行单纯形）。
输出"最优点 + 卡住它的那条红线名字"——这就是初筛结论的标准句式。

## 4. FRC：专属升级件

关键认知：FRC 初筛必须**分两个模式**，混在一起就是审核说的"不能复现真实路线"：

**模式 A：稳态束驱动（TAE 路线）**
- P_NBI 输入维持位形与电流；快离子压强 f_fast、beam-target 聚变项（同磁镜件复用）
- 通量寿命约束：τ_φ ∝ r_s²/η_eff（电阻衰减）需 > 维持补给周期
- Q_eng：NBI η_wp=0.3 进再循环

**模式 B：脉冲压缩（Helion 路线）——0D 最适合算的循环账**
```text
单脉冲：E_cap →(η_comp) 压缩功 → 绝热压缩 T∝B^(4/5)? 用 rigid-rotor 绝热标度
        燃烧时间 ~ τ_N(压缩态) → E_fus
        膨胀做功直接回收：η_rec ≈ 0.7–0.95（Helion 宣称的核心）
循环账：Q_eng_pulse = [η_n·E_n + η_rec·(E_charged+E_plasma)] / (E_cap/η_cap)
        P_net = rep_rate · 净能/脉冲 − 辅助
红线：  rep-rate × 壁热/中子负载、开关器件功率、压缩线圈应力
```
模式 B 是新 solver（`frc_pulsed.py`，复用 rigid-rotor 内核 + 绝热标度），~200 行。
这是五位形升级里**唯一需要新位形级 solver** 的件，但 0D 性质完美（循环就是代数账）。

验收：模式 B 用 Helion 公开参数（Polaris：B~10T 级压缩、rep-rate 量级）跑出
"η_rec 低于某阈值则永不净电"的敏感性结论——这是该路线公认的关键问题，
初筛工具能独立给出这个阈值就算合格。

## 5. 偶极场：专属升级件

最难的一个，因为 τE 无定标。诚实路线：

| 件 | 做法 |
|---|---|
| τE 半预测 | 不再裸输入：τE = f_τ·τ_ref，τ_ref 取湍流 pinch 口径的无量纲组合（gyro-Bohm: τ_gB ∝ a²/(ρ_i v_th/L_p)...），f_τ 用 LDX 实测锚定（LDX τ~0.1s 反推 f_τ 区间），输出时强制带 ×(1/3–3) 不确定度带 |
| 悬浮线圈生存链 | 这是偶极工程初筛的灵魂：中子/热流 → 内环屏蔽厚度 Δ_s → 环有效半径&重量 → 悬浮可行 + 内环低温功率 P_cryo_ring 进再循环；D-T 下 Δ_s 需求会直接把概念杀死或逼到大尺寸——和 arXiv:2602.20564 的结论对照 |
| 燃料路线分叉 | D-T（包层覆盖率仅~0.5，TBR 大概率不达标→标红）vs cat-D-D/D-He3（无 TBR 问题但 Pfus 低 → τE 要求暴涨）→ 初筛输出"两条路各卡在哪" |
| 压缩性窗口 | 已有 β_in≤1 + p_slope 恒等式，加上"剖面陡于边际稳定 → 不可行"作为硬域 |

验收：对 arXiv:2602.20564 的 D-T 偶极电站参数表逐行对照，
能复现其"需要什么尺寸/场/τE 才闭合"的量级结论。

## 8. 升级后它仍然不是什么（提前写好的诚实条款）

即使 E0–E3 全部完成，这仍是**初筛**工具：
- 不预测湍流/破裏/3D 平衡——所有定标外推处都有带宽标注；
- 不替代线圈设计/中子学输运/热工水力——proxy 链只保证"量级和卡点方向正确"；
- 输出的标准句式永远是：**"在 X、Y、Z 假设档位下，该位形的可行窗口为 W，
  最先卡死的约束是 C，结论对参数 p 最敏感（弹性 e）"**——
  而不是"该位形可以/不可以建堆"。
初筛的价值 = 用对的红线把搜索空间砍掉 95%，并告诉重型工具该往哪打。
