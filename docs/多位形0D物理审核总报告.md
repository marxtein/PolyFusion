# 多位形 0D 物理审核总报告

日期：2026-06-10  
对象：PolyFusion release 中五个位形的 0D 物理模型  
范围：托卡马克、磁镜、FRC、偶极场、仿星器  
说明：磁镜已先行完成独立报告，本轮新增 FRC、偶极场、仿星器、托卡马克四份报告。本总报告汇总共性结论和修正路线。

## 1. 总结结论

这套多位形 0D 系统程序有明确价值：它已经不是“一个托卡马克公式套五个名字”，而是给每个位形都写了自己的主闭合逻辑：

| 位形 | 主闭合逻辑 | 当前可信级别 |
---|---|---|
| 托卡马克 | 热功率账 + 输入 `tauE` + IPB98/Greenwald/Troyon 后验 | 最成熟，适合 0D POPCON 基准 |
| 磁镜 | 热中心室功率账 + Pastukhov/GDT/径向端损 | 教学/初筛可用，真实堆缺端塞/快离子/稳定性 |
| FRC | rigid-rotor 剖面 + 压强平衡定密度 + LSX `tau_E` | 教学/趋势可用，真实路线缺形成维持/快离子/脉冲 |
| 偶极场 | 点偶极磁通壳 + `pU^gamma` 边际稳定剖面 + 输入 `tauE` | 剖面教学强，性能预测弱 |
| 仿星器 | 旋转椭圆几何 + `iota` + ISS04/Sudo 后验 | 0D 诊断较强，但缺真实 3D 优化与输运 |

总判断：

```text
公式链：多数能闭合。
名义预设：多数能跑通。
文献量级：托卡马克/仿星器较强；FRC/偶极/磁镜较偏初筛。
真实反应堆预测：五者都还不够。
最大共性问题：输入物理域缺少保护，会产生假结果。
```

如果把这套系统定位为“多位形 0D 教学、趋势扫描、概念初筛平台”，它是有价值的。  
如果定位为“判断哪个位形可以建堆的预测工具”，当前还不够。

## 3. 全位形共同 P0 问题

### 3.1 组分分数未统一校验

多位形都使用：

```text
f12 = 1 - fHe - fimp
```

但没有统一要求：

```text
0 <= f1 <= 1
0 <= fHe
0 <= fimp
fHe + fimp <= 1
Zimp > 0
```

结果是 `fHe=0.7, fimp=0.4` 这种负燃料份额仍能给出输出。部分位形会得到看似正常的 `Pfus/Q/Zeff`，这是最高优先级假结果来源。

### 3.2 `Rw > 1` 导致复数或隐藏复数

托卡马克、仿星器、磁镜、FRC、偶极场都涉及：

```text
Pcycl ∝ (1 - Rw)^0.5
```

当 `Rw > 1`：

- 托卡马克/仿星器会输出复数 `Pheat/Q/H`。
- FRC 会在比较复数和整数时异常。
- 偶极场会出现 `ComplexWarning` 并把虚部丢掉。

应统一校验：

```text
0 <= Rw <= 1
```

### 3.3 剖面指数缺少收敛域保护

托卡马克、磁镜、仿星器使用 `(1 - x^2)^Sn/ST`。当 `Sn/ST < 0` 时，边界可能发散，分母也可能为零。

建议当前阶段统一限制：

```text
Sn >= 0
ST >= 0
```

后续若要允许 hollow/edge-peaked profile，应换成单独剖面模型，而不是直接放开负指数。

### 3.4 `Qfus=1000` 把点火、负加热和异常混在一起

多个模块使用：

```text
Qfus = Pfus/Pheat if Pheat > 0 else 1000
if Qfus <= 0 or Qfus > 1000: Qfus = 1000
```

这会把不同状态混在一起：

- 真实接近点火。
- alpha/charged products 超过损失导致负外部加热。
- 负功率/负体积/非法输入导致异常。

建议统一输出：

```text
Pheat_raw
Qfus_raw
Qfus_capped
ignited_flag
valid_physics_flag
```

### 3.5 POPCON 扫描缺少逐点 invalid/NaN 机制

当前 `scan2d()` 直接调用 solver。若某点异常，可能整张扫描失败；若某点只是物理无效但数值可算，则可能进入 best region。

建议：

- 每个 grid point 先 validate。
- invalid 点填 `NaN` / `null`。
- 输出 `valid` 网格和 `scan_errors` 摘要。
- `best_region_mask` 必须排除 invalid 点。

## 4. 各位形重点问题

### 4.1 托卡马克

强项：

- 反应率、IPB98、Greenwald 文献 benchmark 最强。
- ITER/SPARC/CFETR 等名义点量级合理。
- 适合作为多位形对照基准。

重点问题：

- `tauE` 是输入，H98 是后验，不是预测。
- p-B11 概念点 H98/betaN/betaT 极激进，不能只看 Q。
- `Q=1000` 截断会掩盖负加热/点火/异常。
- 缺 current drive、pedestal、ELM、divertor、disruption、杂质线辐射等。

结论：

```text
可做成熟 0D POPCON；不可做工程级 reactor design。
```

### 4.2 磁镜

强项：

- 把开放场线端损作为主约束，区别于托卡马克。
- Pastukhov/GDT/径向通道的框架方向正确。
- 中心室功率账闭合。

重点问题：

- 端塞电势过简化。
- NBI/快离子/非麦克斯韦缺失。
- alpha 逃逸未闭合。
- DCLC/MHD 稳定性缺失。
- 端部热流工程未闭合。
- Pastukhov 低势垒适用域要标记。

结论：

```text
可做磁镜中心室 classical 0D 初筛；不能预测真实磁镜堆 Q。
```

### 4.3 FRC

强项：

- rigid-rotor 剖面、平均 beta 定理和压强平衡闭合漂亮。
- LSX 约束定标有实验量级锚。
- FRC-DT / Helion / C-2W 预设能跑出趋势。

重点问题：

- `x_s > 1` 可产生负 beta 和假 Q。
- `f_shape` 可越过几何范围。
- LSX 定标外推到反应堆/脉冲压缩风险大。
- 缺形成维持、n=2/tilt 稳定、NBI 快离子、开场线/SOL、能量回收。

结论：

```text
可做 FRC 热 0D 趋势模型；不能复现 Helion/TAE 真实路线。
```

### 4.4 偶极场

强项：

- 点偶极磁通壳几何和边际稳定剖面很清晰。
- `pU^gamma`、`n∝L^-4`、`T∝L^-8/3` 的教学价值高。
- 壳积分比体平均更适合强峰化剖面。

重点问题：

- `tauE` 完全输入，没有预测能力。
- `L_in >= R_p` 可产生负体积、负功率和假 `Q=1000`。
- `beta_in > 1` 单点仍输出。
- 缺源汇自洽、有限线圈场、热电子环、湍流 pinch、悬浮工程。

结论：

```text
可解释偶极剖面自组织；不能据此判断偶极堆性能。
```

### 4.5 仿星器

强项：

- ISS04/Sudo 使用正确，W7-X 纪录炮和多装置 `iota` 锚点支撑较强。
- `N_fp/kappa_s/iota_geom` 让仿星器不再只是“无电流托卡马克”。
- HELIAS 点落在较合理的 0D 反应堆窗口。

重点问题：

- 旋转椭圆只是低阶几何，不是 VMEC/真实 3D 磁场。
- `iota=0` 会导致 `H_ISS04=inf`。
- `f_ren` 是外部品质因子，真实位形优化未建模。
- 缺 neoclassical/turbulent transport、bootstrap current、island divertor、alpha confinement。

结论：

```text
可做仿星器 0D 诊断和教学；不能替代真实 3D stellarator design。
```

## 5. 建议修正路线

### Phase 1：统一物理域校验

先做最小但最高收益的防假结果层：

- 通用组分 validator。
- 通用 `Rw`、`fsig`、`tauE`、温度/密度正值 validator。
- 各位形专属几何域：
  - Tokamak：`g>=0`、`Sw>0`、`q/beta/nGw` 后验标记。
  - Mirror：`R_mirror>1`、`phi_i>0`、`raw_beta<1`。
  - FRC：`0<x_s<1`、`2/3<=f_shape<=1`。
  - Dipole：`r_ring<L_in<R_p`、`Vp>0`、`beta_in` 标记。
  - Stellarator：`iota_used>0`、`kappa_s>0`、`N_fp>0`。
- 非有限结果统一 invalid。

### Phase 2：POPCON invalid 点和状态显示

- `scan2d()` 不让坏点拖垮整图。
- invalid 点显示空洞。
- best region 必须排除 invalid。
- `Q=1000` 改成明确状态：capped / ignited / invalid。

### Phase 3：文档/UI 统一可信级别

每个位形 UI 帮助中加入一句：

```text
本模块为 0D scoping model，适合教学和趋势扫描；不含完整稳定性、输运和工程系统。
```

并给每个位形列出“缺失的真实物理”。

### Phase 4：逐位形升级真实物理

优先级建议：

1. 托卡马克：Q 状态、后验红线、divertor/辐射提示。
2. 磁镜：端塞/alpha/稳定性最小模型。
3. 仿星器：`f_ren`/iota 来源、neoclassical proxy。
4. FRC：稳定性和形成维持 proxy。
5. 偶极：输运 `tauE` proxy 和有限线圈场。

## 7. 总体可信度排序

按“0D 审核可信度”排序，而不是按“哪个真实装置更好”：

```text
托卡马克 > 仿星器 > FRC > 磁镜 > 偶极场
```

解释：

- 托卡马克：文献 benchmark 和系统程序传统最强。
- 仿星器：ISS04/Sudo 有数据库支撑，但几何是低阶近似。
- FRC：剖面/压强平衡漂亮，约束外推较弱。
- 磁镜：端损框架正确，但真实端塞/快离子/稳定性缺口大。
- 偶极场：理论剖面漂亮，但 `tauE` 完全输入，性能预测最弱。

这个排序只表示“当前代码作为 0D 模型的闭合程度”，不表示真实物理路线优劣。

## 8. 最终建议

当前最值得做的不是立刻加入复杂高阶物理，而是先加“物理域防护层”。因为现在最大风险不是模型太简单，而是简单模型在无效输入下还会给出漂亮数值。

一句话路线：

> 先让每个位形知道“哪些点不能算”，再让 POPCON 知道“哪些点不能画成可行窗口”，最后再逐步补每个位形真正缺的高阶物理。

完成 Phase 1 和 Phase 2 后，这套平台就可以比较稳地定位为：

```text
多位形 0D 教学 + 参数初筛 + POPCON 趋势平台
```

在完成更高阶稳定性/输运/工程模块前，不建议把任何位形的高 Q 区域解释为真实反应堆可行性证明。

## 9. 物理可靠性再审：从“能闭合”到“能设计”

这轮再审的核心结论比前面的代码审核更严格：

```text
代码和公式闭合 ≠ 物理上足以指导装置设计。
当前平台适合做 0D 教学、趋势扫描和早期概念初筛；
若目标是辅助真实聚变装置设计，需要增加物理域、约束红线、输运/稳定性和工程闭合。
```

### 9.1 设计可靠性分级

这里的分级不是位形路线优劣，而是“当前代码能多可靠地支持设计判断”：

| 位形 | 当前 0D 物理可靠性 | 可放心使用的范围 | 不能直接相信的输出 |
|---|---:|---|---|
| 托卡马克 | 中-高 | D-T 0D POPCON、ITER/SPARC/CFETR 量级、H98/beta/q/Greenwald 后验 | 稳态电站工程、divertor/current drive/ash、p-B11 可行性 |
| 仿星器 | 中 | ISS04/Sudo 初筛、HELIAS/W7-X/LHD 量级对照 | 真实 3D 位形优化、alpha loss、island divertor、coil feasibility |
| 磁镜 | 中-低 | 中心室 classical 端损趋势、镜比/电势敏感性 | 端塞/NBI/快离子/稳定性/端部热流自洽后的 Q |
| FRC | 中-低 | Rigid-rotor、压强平衡、高 beta 热 0D 趋势 | Helion/TAE 真实路线、脉冲压缩、NBI 快离子、形成维持 |
| 偶极场 | 低-中 | `pU^gamma` 边际稳定剖面教学、给定 tauE 功率账 | reactor tauE 预测、有限线圈/源汇/内线圈工程 |

一句话：

```text
最可靠的是托卡马克 D-T 0D 初筛；
最需要谨慎的是偶极场的 Q，因为 Q 主要由输入 tauE 决定；
最容易被误读的是 FRC/磁镜，因为它们的真实路线往往依赖当前模型没有的快离子、端部或脉冲物理。
```

### 9.2 当前所有位形的共同硬伤

1. 高 Q 不是设计可行性证明。只要 `tauE`、`f_ren`、端塞电势、alpha 沉积、快离子稳定化等关键物理是输入或缺省假设，高 Q 就只是“在这些假设下的功率账结果”。
2. POPCON 没有可靠的 invalid mask 时，会把不该相信的点画成窗口。对设计工具来说，这比公式少一点复杂性更危险。
3. 经验定标不能无边界外推。IPB98、ISS04、Sudo、LSX、Pastukhov/GDT 都有适用域；出了适用域应该降级为“假设扫描”，不能保持同等可信度。
4. 真实装置常常不是 core power balance 卡住，而是稳定性、边界热流、快粒子损失、材料、线圈、端部工程、电流驱动、灰份和杂质卡住。

### 9.3 更可靠的总方案

建议把平台升级成三层可信度架构：

#### Level 0：物理域防护层

所有位形统一输出：

```text
valid_input_flag
valid_physics_flag
valid_numeric_flag
invalid_reasons[]
Q_raw
Q_capped
ignited_flag
assumption_tags[]
```

这一层必须先做。没有它，后续再复杂的物理都会被非法点污染。

#### Level 1：保守 0D 设计红线层

每个位形的 best region 不只看 Q，还要看：

- 托卡马克：`H98`、`betaN`、`q/q95`、`nbar/nGw`、`Pwall`、L-H/divertor/current-drive proxy。
- 仿星器：`H_ISS04`、`nbar/Sudo`、`betaT`、真实 `iota/ripple` 来源、alpha loss、divertor proxy。
- 磁镜：`Past_domain`、端塞电势/功率、`P_end_flux/P_coll_flux`、alpha loss、DCLC/MHD proxy。
- FRC：`0<x_s<1`、`s_param` 有效域、LSX 外推倍率、NBI/脉冲模式标记、稳定性 proxy。
- 偶极场：`tauE_required`、`tauE_required/experiment_anchor`、`beta_in`、finite-coil 几何、内线圈热负荷。

#### Level 2：位形专属高阶物理层

这一层决定它能否从“教学/初筛”升级到“设计前端”：

- 托卡马克：隐式 H98 求解、current drive/bootstrap、pedestal/divertor、ash/杂质、系统工程。
- 仿星器：VMEC/真实 3D 磁场接口、neoclassical/turbulent proxy、alpha orbit、island divertor、coil 指标。
- 磁镜：端塞多区模型、NBI/快离子 Fokker-Planck proxy、DCLC/MHD 稳定性、direct conversion/collector。
- FRC：稳态束驱动模式和脉冲压缩模式分开、快离子/形成维持/稳定性/能量回收。
- 偶极场：finite-coil 磁场、输运定标或实验锚点比、源汇平衡、内线圈屏蔽和热负荷。

### 9.4 给使用者的判读规则

以后读任何 POPCON 图，建议先问四个问题：

1. 这个高 Q 点是否在输入域和物理域内？
2. 关键约束是模型预测的，还是我手动输入/假设的？
3. 所需 H 因子、tauE、f_ren、端塞电势、快离子沉积是否有实验或文献量级支撑？
4. 缺失的位形专属关键物理，会不会正好是这个路线成败的主因？

如果第 2 条答案是“关键约束由我输入”，那这个点只能叫：

```text
assumption-conditioned operating point
```

不能叫：

```text
predicted feasible reactor point
```

### 9.5 总体结论

物理可靠性上，当前平台最适合的定位是：

```text
多位形 0D 教学 + 趋势扫描 + 早期概念筛选 + 需求反推工具
```

它可以告诉你：

```text
如果某个位形要达到目标 Q，需要多大的 tauE/H/f_ren/端塞电势/稳定性裕度。
```

它还不能直接告诉你：

```text
这个位形真实装置一定能达到这些 tauE/H/f_ren/端塞电势/稳定性裕度。
```

更可靠的开发方向不是马上把每个公式堆复杂，而是先把“哪些结果可信、哪些只是条件假设”做成机器可读输出，再逐步接入每个位形真正决定成败的高阶物理。
