# 偶极场 0D 物理闭合性审核报告

日期：2026-06-10  
对象：`polyfusion/configs/dipole.py`、`polyfusion/configs/base.py`、`polyfusion/scan.py`，对照 `docs/26_偶极场代码说明文档.md`、`docs/10_偶极场0D物理调研.md`、`docs/11_偶极场模型实现报告.md`  
结论级别：物理审稿式问题清单；本报告不修改源码

## 1. 总结结论

偶极场模块的几何和剖面闭合很漂亮：它没有继续使用早期的粗糙球壳体积，而是用了点偶极磁通壳几何：

```text
V_enc(L) = 64 pi L^3 / 105
dV/dL = 64 pi L^2 / 35
```

剖面也不是任意指定，而是来自 levitated dipole 的可压缩性边际稳定逻辑：

```text
U(L) ∝ L^4
delta(p U^gamma) = 0, gamma = 5/3
=> p ∝ L^(-20/3)
=> n ∝ L^(-4), T ∝ L^(-8/3)
```

因此，作为“悬浮偶极场为什么能自组织成陡剖面”的教学模型，它是有物理骨架的。

但是，偶极场模块目前不能作为真实偶极聚变堆性能预测工具。最大原因是：

> 约束时间 `tauE` 是外部输入，不是由偶极输运模型预测出来的。

也就是说，高 Q 结果主要反映“你给了多长的 `tauE`”，而不是代码证明这个装置真的能达到这个约束。尤其 `Dipole-DHe3` 当前给出 `Q≈9.08`，这个数不能被解读为 D-He3 偶极场堆可行，因为它完全依赖 `tauE=10 s`、理想边际剖面和没有自洽输运/源汇的假设。

当前最危险的代码问题是：`L_in >= R_p` 时会出现负体积、负聚变功率、负辐射功率，但 `Qfus` 被截断成 `1000`。这是明确的 P0 假结果。

## 2. 已经闭合的部分

### 2.1 点偶极磁通壳几何

代码采用：

```text
L_in = L_in_fac * r_ring
V_p = 64 pi (R_p^3 - L_in^3) / 105
dV/dL = 64 pi L^2 / 35
B(L) = B_ring (r_ring/L)^3
```

`test_dipole_benchmark.py` 已验证：

- 壳体积解析式与数值积分一致。
- `U_ratio = (R_p/L_in)^4`。
- `B_in/B_out = (L_out/L_in)^3`。
- LDX 尺度下体积约 `15.1 m^3`，与 5 m 级实验真空室量级相符。

这说明几何层是可信的。

### 2.2 边际稳定剖面

代码实现：

```text
n(L) = n0 (L_in/L)^4
T(L) = T0 (L_in/L)^(8/3)
p(L) ∝ L^(-20/3)
```

benchmark 验证 `p_slope = -20/3`，并验证 beta 的 `L^(-2/3)` 衰减。这个部分与 Hasegawa/Kesner/Mauel 的 levitated dipole 理论方向一致：偶极场依靠磁通管体积随半径急剧膨胀，使得可压缩性稳定条件自然给出强峰化剖面。

### 2.3 逐磁通壳功率积分

聚变功率、轫致辐射和回旋辐射都沿 L 壳积分：

```text
Pfus = ∫ n1(L) n2(L) <sigma v>(T_i(L)) dV
Pbrem = ∫ ne(L)^2 sqrt(Te(L)) ... dV
Pcycl = ∫ ne(L)^0.5 Te(L)^2.5 B(L)^2.5 ... dV
```

这比用单一体平均温度更合理，因为偶极剖面非常陡，功率高度集中在内边界。sanity 测试也验证了外半径从 6 到 10 m 时 `Pfus` 基本不变，说明功率确实集中在内侧高温高密度区。

### 3.3 边界测试暴露的问题

#### P0：`L_in >= R_p` 仍计算，产生负体积和假 `Q=1000`

测试：

```python
run_case({"L_in_fac": 20}, preset="Dipole-DD", config="dipole")
```

输出摘要：

```text
Vp = -13404 m^3
Pfus = -466266 MW
Pbrem = -196107 MW
beta_in = 3.87e6
Pheat = 8000 MW
Qfus = 1000
```

这是最严重的问题。`L_in = L_in_fac * r_ring` 必须满足：

```text
r_ring < L_in < R_p
```

否则等离子体体积为负，磁通壳积分方向反了，所有功率结果都失去物理意义。当前 `Qfus` 的截断逻辑把负聚变功率导致的异常增益变成了 `1000`，会制造“极好点”的假象。

#### P1：`beta_in > 1` 只作为窗口排除，单点仍给结果

测试：

```python
run_case({"n0": 1e21}, preset="Dipole-DD", config="dipole")
```

输出：

```text
beta_in = 2.293
Pfus = 5.956 MW
Pheat = 16.672 MW
Qfus = 0.357
```

文档说 `beta_in ≲ 1` 是局域压强不能超过内边界磁压的硬提示。当前 best-window 里有 `beta_in <= 1`，但单点计算没有报错或警告。至少应在输出中标记 invalid/warning，避免用户把超压点当成可行设计。

#### P0：非法组分仍给结果

测试：

```python
run_case({"fHe": 0.7, "fimp": 0.4}, preset="Dipole-DD", config="dipole")
```

输出：

```text
Zeff = 8.0566
Pfus = 0.00536 MW
Pheat = 160.903 MW
beta_in = 1.871
```

此时燃料份额 `f12 = -0.1`，物理上无效。该问题与 FRC、磁镜、仿星器、托卡马克共通，应统一校验燃料/杂质组分。

#### P1：`Rw > 1` 的复数被悄悄丢掉虚部

测试：

```python
run_case({"Rw": 1.2}, preset="Dipole-DD", config="dipole")
```

运行时出现：

```text
ComplexWarning: Casting complex values to real discards the imaginary part
```

这是因为 `Pcycl` 中有 `(1 - Rw)^0.5`。当 `Rw > 1` 时进入复数，代码通过 `float(...)` 把虚部丢掉。相比直接崩溃，这更危险，因为用户看不到明显错误。

## 4. 关键物理缺口

### 4.1 `tauE` 是输入，不是预测

偶极场最大的未闭合处是约束时间。代码文档也明确承认：没有成熟的 dipole `tau_E` 定标律，所以 `tauE` 作为输入保留。

这意味着：

```text
Qfus = 代码功率账 + 用户假设的 tauE
```

而不是：

```text
Qfus = 偶极场物理自己预测的反应堆性能
```

因此所有高 Q 预设都必须附带 `tauE` 假设强度说明。

### 4.2 边际稳定剖面没有源汇自洽

`n ∝ L^-4`、`T ∝ L^-8/3` 来自理想边际稳定约束，但真实装置还需要考虑：

- ECRH 或其他加热位置。
- 粒子源和损失。
- 径向扩散和湍流 pinch。
- 热电子环和冷背景等双温/多组分结构。
- 内边界与线圈附近真实磁场偏离点偶极。

当前代码直接把边际剖面当作全局稳态剖面使用，没有解源汇平衡。

### 4.3 点偶极近似在内边界附近可能失准

`B(L) = B_ring (r_ring/L)^3` 是点偶极远场表达式。对于 `L_in_fac = 1.5`，内边界离环并不算很远，真实有限尺寸环场会偏离点偶极。

这不会否定模型的教学价值，但会影响 `B_in`、`beta_in`、Pcycl 和内侧高温区的功率密度。

### 4.4 D-D / D-He3 燃料循环与直接能量转换缺失

偶极场路线常被讨论为 D-D 或高级燃料概念。但当前模型没有：

- D-D 产生的 T/He3 后续燃烧和灰分演化。
- 中子、带电产物和直接能量转换分离。
- alpha/质子轨道沉积。
- 线圈屏蔽、悬浮低温冷却、核热负载。

因此不能凭 `Qfus` 判断电站级可行性。

## 6. 修正优先级

### P0：必须防止假结果

- 校验 `r_ring > 0`、`R_p > 0`、`L_in_fac > 1`。
- 校验 `L_in = L_in_fac * r_ring < R_p`。
- 校验 `Vp > 0`、`B_in > 0`、`B_out > 0`。
- 校验 `0 <= f1 <= 1`、`0 <= fHe`、`0 <= fimp`、`fHe + fimp <= 1`、`Zimp > 0`。
- 校验 `0 <= Rw <= 1`。
- 如果 `Pfus < 0`、`Pbrem < 0`、`Pcycl` 非实数，不得输出有效 `Qfus`。

### P1：把 beta 和 tauE 假设显式化

- `beta_in > 1` 应标记为 invalid 或至少 warning。
- 输出 `tauE_assumption = input` 或文档/UI 明确标注 `tauE` 是用户假设。
- best-window 中保留 `beta_in <= 1`，并建议加入 `tauE <= 用户可信上限` 或 `H/benchmark` 类比指标。

### P2：若要判断真实偶极堆

需要新增：

- 偶极湍流 pinch / 径向输运模型。
- 加热与粒子源分布，求解源汇平衡剖面。
- 有限尺寸线圈磁场。
- 悬浮线圈工程、低温冷却和核热负荷。
- D-D 产物循环、灰分和直接能量转换。
- 热电子环/多温组分模型。

## 7. 推荐对外表述

建议将偶极场模块描述为：

> 偶极场模块是基于点偶极磁通壳几何和可压缩性边际稳定剖面的 0D 功率平衡模型。它适合解释 levitated dipole 的剖面自组织、功率集中和参数趋势；但 `tauE` 是输入而非预测，不包含源汇自洽、湍流 pinch、有限线圈场、热电子环、悬浮线圈工程和高级燃料能量回收，因此不应直接用于声明偶极聚变堆 Q。

## 9. 最终判断

偶极场模块的几何和剖面理论闭合度高，适合教学和趋势初筛。它最有价值的地方是把 `U(L) ∝ L^4` 与 `pU^gamma` 边际稳定联系起来，并用磁通壳积分表达功率集中。

但当前它不是可预测的反应堆模型。所有 Q 结果都必须带上前提：“给定 `tauE` 后的功率账”。在修正优先级上，应先防止负体积、负功率、复数辐射和非法组分进入输出；然后再考虑输运和工程闭合。

## 10. 物理可靠性再审：能不能用于装置设计？

偶极场模块需要最谨慎。它的理论剖面很漂亮，但设计可靠性最弱：

```text
偶极场当前模型可以解释 levitated dipole 为什么可能有稳定陡剖面；
不能预测 reactor tau_E；
不能用当前 Qfus 判断偶极聚变堆可行性。
```

### 10.1 可靠的部分

- 点偶极磁通壳几何、`U(L) ∝ L^4`、`n ∝ L^-4`、`T ∝ L^-8/3`、`p ∝ L^-20/3` 的链条是物理上有来源的。它表达的是偶极场“磁通管体积随半径急剧膨胀，所以陡压强剖面仍可稳定”的核心。
- 对给定剖面做磁通壳积分，比用均匀体平均更适合偶极场，因为功率和辐射确实高度集中在内侧高场/高密区。
- `beta_in`、`U_ratio`、`p_slope` 作为诊断输出有教学价值。

### 10.2 不可靠的设计环节

第一，`tauE` 是输入，不是预测。偶极场能否成为聚变堆，核心问题恰恰是能量和粒子约束能否达到反应堆量级。当前代码把最难的问题留给用户输入，所以高 Q 本质上是“给了足够好的 tauE 后功率账变好”，不是代码证明了偶极约束足够好。

第二，点偶极和真实悬浮线圈差别很大。真实装置有有限尺寸超导环、支撑/悬浮系统、线圈屏蔽、环附近空腔、偏离理想偶极的磁场、线圈热负荷和中子屏蔽。0D 点偶极体积不能替代工程几何。

第三，源汇没有自洽。偶极场的陡剖面依赖湍流 inward pinch、粒子源、热源沉积和边界损失的平衡。当前模型直接规定剖面，不求解粒子源、加热沉积、灰份排出、杂质累积和边界回收。

第四，D-D 或先进燃料场景尤其不能只看 Q。D-D 中子/氚副产物、轫致辐射、灰份、直接能量转换和屏蔽都会改变系统级可行性。

### 10.3 设计使用等级

| 用途 | 当前可信度 | 说明 |
|---|---:|---|
| 教学解释 `pU^gamma` 稳定剖面 | 高 | 理论链条清楚 |
| 给定 tauE 后看功率账 | 中 | 数学闭合，但强依赖输入 |
| 预测偶极场约束性能 | 低 | 没有成熟 tauE 定标 |
| 反应堆工程设计 | 很低 | 缺有限线圈、屏蔽、源汇、输运 |
| 判断真实偶极聚变路线可行 | 不足 | 关键物理未闭合 |

### 10.4 更可靠的偶极场方案

建议把偶极模块从“输入 tauE 的功率账”升级为“剖面理论 + 输运假设显式化”的分层模型：

1. 几何层：保留点偶极解析模型，同时加入 finite-coil 修正或从磁场网格读入 `B(R,Z)`，用磁通面体积 `U(psi)` 替代简单 `L^4`。
2. 剖面层：允许三种剖面假设并同时输出：理想边际稳定剖面、LDX/RT-1 经验剖面、用户给定剖面。POPCON 必须标明剖面来源。
3. 输运层：`tauE` 不再只给单值，至少给 `tauE_assumed`、`tauE_required_for_Q`、`tauE_required_vs_LDX_scale`。如果没有可靠定标，就输出“所需 tauE 离实验锚点多少倍”。
4. 源汇层：加入加热沉积、粒子补给、灰份排出、边界损失和内线圈热负荷。偶极场能不能做装置，工程上内线圈是第一等约束之一。

最低可接受升级：

```text
偶极设计判断 = 给定 tauE 功率账
             + 所需 tauE/实验锚点比
             + finite-coil 几何
             + beta_in 与线圈屏蔽约束
             + 源汇/灰份/内线圈热负荷
```

在这些补齐前，偶极 POPCON 图的高 Q 区域只能解释为“在假定约束时间下的功率账窗口”，不能解释为“偶极场自己预测出的可运行窗口”。

新增参考锚点：

- Kesner & Mauel 对 levitated dipole 的边际稳定、磁通管体积和 inward pinch 物理作了系统综述：https://www1.psfc.mit.edu/ldx/pubs/kesner_mauel_PlPhysRep23.pdf
- MIT PSFC 偶极聚变概念白皮书讨论了偶极场用于聚变的吸引力，也体现其仍属概念级路线：https://www1.psfc.mit.edu/ldx/pubs/dipole_wp.pdf
- LDX 实验资料可作为实验锚点，但它不是反应堆尺度 tauE 定标：https://www1.psfc.mit.edu/ldx/
