## (a) Scheme D — 单一近轴几何

### 做了什么 / 为什么
升级前仿星器同时存在两套几何：旧的"旋转椭圆"闭式解（由 `kappa_s` 驱动）和近轴展开。两者并存导致：近轴模式下 `kappa_s` 失效（inert），旧模式下 `delta_h` 对 `iota` 失明。这是概念混乱（conceptual integrity 受损）。

Scheme D 砍掉旧路径，只保留 **一阶近轴展开（Garren-Boozer / Mercier，Landreman-Sengupta-Plunk 形式，即 pyQSC 的 "r1 construction"）** 作为现代优化仿星器的标准解析表示。

### 怎么做
- 磁轴是三维 Fourier 曲线 `R = Σ rc[n] cos(n·N_fp·φ)`，`Z = Σ zs[n] sin(n·N_fp·φ)`；默认 `rc=[R0, delta_h]`、`zs=[0, -delta_h]`，也可传自定义 `rc`/`zs`。
- 单一塑形量 `etabar`（B = B0[1 + r·etabar·cosθ]，要求 ≠ 0）。**拉长比 elongation 是导出量，不是输入。**
- 周期 σ 方程（Riccati 型）用 Newton 迭代解出自洽的轴上 `iota`，**同时**包含轴扭率（torsion）贡献与完整 elongation 剖面 e(φ)。见 `polyfusion/nearaxis.py`，已逐点对齐 pyQSC（曲率/扭率 rtol 1e-11，iota 1e-8）。
- 体积用 Pappus + 通量守恒截面积 πa²；面积用弧长加权 elongation 剖面。
- 实测覆写（D1）：真机（W7-X 准等动、LHD heliotron）单谐波近轴无法表示时，给定显式 `iota`（用于 ISS04/Sudo 闭合），并可选 `Vp_override`/`Sw_override` 把功率账锚到真实几何。

### before → after
- before：`kappa_s` 旋转椭圆 + 近轴，两套并存、互相失明。
- after：单一近轴；`etabar` 唯一塑形；UI 面板含 `etabar`/覆写/自定义轴 + 壁层（gap g 可见）。

### 测试证据
- `test_nearaxis_benchmark.py`：曲率/扭率/iota/elongation/helicity 对齐 pyQSC published r1 sections 5.1/5.2，含尺度不变性、etabar 符号不变性、网格收敛、平面圆轴 iota→0 极限。
- `test_stellarator_overrides.py`：`Vp_override` 线性 rescale Pfus；`Sw_override` 精确设定 `Pwall=(Pfus+Pheat)/Sw`；平面实测机（delta_h=0, iota=0.40）可运行；自定义 Fourier 轴改变 `iota_geom`。

### 已知局限
- 一阶近轴截面是**纯椭圆**——不显示真机的 bean/crescent（→ 本轮 (d) 解决）。
- 单谐波默认轴对强 3D 真机（W7-X/LHD）不忠实，必须靠实测覆写。
- σ 方程对过大 `etabar`/强轴会 Newton 不收敛（合理的物理边界，非 bug）。

### 做了什么 / 为什么

1. **`test_golden.py`**：本是 pytest 用例，被当成独立脚本跑 → 误判失败。修：明确用 `python -m pytest polyfusion/tests/test_golden.py` 运行。

这是 **stale test 的根因修复**，没有改动物理或放宽锚点。

## (d) 本轮工作

### (d.1) 二阶（r²）近轴 bean/crescent 截面

#### 做了什么 / 为什么
一阶近轴面是纯椭圆（X1=(etabar/κ)cosθ，Y1=(κ/etabar)(σcosθ+sinθ)）。真机（W7-X 等）的 bean/三角/crescent 截面只在**二阶（r² 项）**出现。本轮把二阶形状加进来，让 UI 磁面视图像真机。

#### 怎么做
- 把 pyQSC `calculate_r2`（Landreman & Sengupta, J. Plasma Phys. 85 (2019) 905850006，"Direct construction ... Part 2"）**移植成 numpy**，特化到本 0-D 模型用的 **真空 + 仿星器对称** 情形：I2=0、p2=0、B2s=0、σ0=0、sG=spsi=+1、B0=1。这把压强项（beta_1s）和全部电流项（I2_over_B0）清零，剩一个纯 numpy 线性方程组解出 X20、Y20。
- `solve_near_axis(..., order="r2", B2c=...)` 返回 `second_order` 载荷：Frenet 系数 X20/X2c/X2s、Y20/Y2c/Y2s、Z20/Z2c/Z2s；**一阶行为仍是默认且不变**。
- `section_outlines` 用二阶面重建截面：
  `P(θ)=axis + X n̂ + Y b̂ + Z t̂`，
  `X=r·X1c·cosθ + r²(X20+X2c·cos2θ+X2s·sin2θ)`，Y、Z 同理（Z 无一阶）。
- **显示半径上限**：近轴展开只在 r 足够小时有效；在反应堆量级小半径上 r² 系数可超过 r¹，故形状视图画在 `a_disp ≤ a`，使二阶位移不超过一阶的 `_R2_DISPLAY_CAP=0.5`，避免自交的"乱麻"截面。这纯属外观，**不动功率账**。r² 解失败时回落一阶（`metric_mode` 标记走了哪条路）。

#### 参考值的来源（关键诚实点）
本机 Microsoft Store Python 装不上 scipy（PyPI 镜像哈希不匹配，`THESE PACKAGES DO NOT MATCH THE HASHES`），pyQSC 因此不可直接 import。解决：写了一个 **numpy-only 的 scipy shim**（仅 `toeplitz` / 构造期 `CubicSpline` / `minimize_scalar` / `netcdf` stub），让 pyQSC 的 r1+r2 路径跑起来，把 r2 系数 dump 成打包 golden `polyfusion/tests/nearaxis_r2_golden.json`。该 shim 的 **O(r¹)（曲率/扭率/σ/iota）复现本仓库已验证的求解器到 < 1e-13**，所以它产出的 O(r²) golden 可信。shim 与生成脚本是**仓外**临时件，发布代码保持 numpy-only、零 scipy/pyQSC 依赖。

#### before → after
- before：UI 磁面是纯椭圆。
- after：UI 磁面显示二阶 bean/crescent；强塑形（更大 etabar/B2c）改变截面但被显示上限约束。

#### 测试证据
- `test_nearaxis_r2_benchmark.py`：X20/X2c/X2s/Y20/Y2c/Y2s/Z20/Z2c/Z2s 对齐 pyQSC published r2 sections 5.1/5.2/5.4，**实测最大偏差 < 2e-12**（容差 1e-9）；并验证默认 order="r1" 无二阶载荷、r→0 时二阶面退回一阶椭圆。
- `test_stellarator_r2_shape.py`：截面非中心对称（bean，central asymmetry ~0.5）、字典契约保留、`a_disp≤a` 显示上限、B2c 真实改变边界、且 `A_flux` 仍是一阶 πa²（功率账未动）。
- `test_stellarator_benchmark.py`：磁面块更新为二阶默认（`metric_mode="near-axis-r2"`、有界 `a_disp`、闭合非零投影面积），并新增"功率账锚点 `A_flux=πa²` 不变"的断言。

#### 已知局限
- 二阶面只在 **真空 + 仿星器对称（B2s=0, sigma0=0, I2=0, p2=0）** 下移植；非对称/有电流/有压强情形未做（超出 0-D 形状视图需要）。published r2 sections 5.3/5.5 因含 I2/p2/B2s/sigma0 故意排除在 benchmark 之外。
- `a_disp` 上限是**外观选择**（cap=0.5），不是物理半径；形状视图是定性 cartoon。
- 投影到 (R,Z) 平面时沿用一阶 cartoon 的近似（固定 φ 切面、忽略点的环向位移），未做 pyQSC `Frenet_to_cylindrical` 的完整环向重映射。
- elongation 诊断仍取一阶 `na.elongation`（标注为一阶）。

### (d.2) 真机 `Sw_override`

#### 做了什么 / 为什么
W7-X/HSX/CFQS/LHD 预设设了实测 `iota`+`Vp_override`，但 `Sw_override=0`，壁面积来自近轴 elongation 剖面——对这些小机器极端失真（HSX elongation ~384）→ `Pwall=(Pfus+Pheat)/Sw` 畸变。当前影响虽可忽略（Qfus≈0, Pwall≈0），但是建模硬伤。

#### 怎么做
在 `polyfusion/presets/stellarator.json` 给四台真机加 `Sw_override` [m²]：
- W7-X **128**、LHD **120**（取自公开等离子体表面估计）；
- HSX **9.1**、CFQS **12.6**（按 `2π·R0 · 2π·a · sqrt((1+κ²)/2)`，κ~1.5 估计）。
全部标注 "approx, confirm vs published"（JSON `_notes` 块，加载器忽略该键）。概念堆 HELIAS/NAE-QA 保持 `Sw_override=0`（纯近轴）。

#### before → after
| 机器 | before Sw (近轴) | after Sw (实测覆写) |
|------|------------------|----------------------|
| W7-X | 502.8 | 128.0 |
| LHD  | 414.4 | 120.0 |
| HSX  | 72.1  | 9.1 |
| CFQS | 106.3 | 12.6 |

#### 测试证据
- `test_stellarator_presets_pwall.py`：6 个仿星器预设 `valid=1`、`Pwall` 有限合理；四台真机壁面积落在合理包络内、`Pwall==(Pfus+Pheat)/Sw` 一致。
- `test_stellarator_overrides.py` 等其余测试保持绿。

#### 已知局限
- W7-X/LHD 取公开估计，HSX/CFQS 是几何近似估计（κ~1.5 假设），均为 **approx**，需对照权威文献核实。

## (e) 评审后修复（UI 越界 + 预设几何）

用户验收时发现两个问题，已修：

### (e.1) 仿星器参数输入框越界
- 根因：`.pgrid` 网格项 `.fld` 缺 `min-width:0`，`1fr` 列无法收缩到内容最小宽以下，右列（A/δh/g/Sw_override）与整宽 rc/zs 行溢出参数面板约 133px，把单位标签 `[m]`/`[1/m]`/`[m³]`/`[m²]` 顶出可视区。
- 修：`.fld` 加 `min-width:0`。浏览器内验证：溢出输入 0，单位可见。

### (e.2) 几组预设几何很怪（微观斑点 / 针状 / 自交）
- 根因：真机（W7-X/LHD/HSX/CFQS）单谐波近轴 elongation 极端（HSX 384、W7-X 50、LHD 41、CFQS 350）。其一阶 elongation ∝ κ²/etabar²，预设里 etabar 是占位小值（0.04–0.08）→ 针状椭圆。叠加 (d.1) 的 r2 显示半径上限：旧逻辑把**整个面**画在受限半径上 → 极端拉长机器的等离子体缩成一个斑点（W7-X 截面尺度 0.003 m），概念堆也被缩到 ~14% 尺寸。
- 修两处：
  1. `section_outlines`：一阶体按**真实小半径 a** 画（尺寸正确），只把**二阶 wobble** 限在 `r2r≤a`（按 cut，r² 位移 ≤ `_R2_DISPLAY_CAP`·r¹）。等离子体不再缩成斑点、不自交。
  2. 真机 etabar 调到给出适中显示 elongation（W7-X 0.119 / LHD 0.405 / HSX 0.948 / CFQS 0.711）。**对功率账安全**：这些预设覆写 iota/Vp/Sw，etabar 只影响显示形状（JSON `_notes` 记录）。
- 新 `test_stellarator_preset_shapes.py`：每个预设渲染为简单（非自交）、尺寸 ~a 的闭合曲线。浏览器内验证 W7-X 现显示 3 个可见嵌套截面。
- 诚实局限：单谐波近轴仍无法给出真 W7-X 那样的 elong~1 bean（本轴最优 ~13）；要真形需多谐波轴/B2c 调参，超出范围。
- commit：`0b0d553`（UI）、`64d2bd3`（几何）。

## (f) 真机几何贴近真实（显式边界模型）

承 (e)：把 etabar 调一调只是缓解，真机的近轴针状/旋转椭圆**本质上画不像真机**。用户复评指出 W7-X 偏差大、LHD「只画了一个」。查文献后改为显式边界。

### 根因
- **LHD 只画一个**：LHD 预设 `delta_h=0` → 平面圆轴 → 三个切面（φ=0/T/4/T/2）落在同一轴点、Frenet 标架恒定 → 三个截面完全相同 → 重叠成一个。
- **W7-X 等偏差大**：单谐波近轴只能给椭圆，画不出 W7-X 的 bean（肾形）↔triangle 形变、LHD 的 l=2 旋转椭圆、CFQS 的 QA D 形。

### 文献依据
- W7-X：5 周期，截面沿半个周期 **bean(φ=0)→三角形**，角部 elongation 达 ~3.6。
- LHD：l=2/m=10 heliotron，R0=3.9 / a~0.6，椭圆截面随环向角**旋转**（每周期 ~π）。
- CFQS：2 周期，asp，比 ~4，准轴对称（QA，类托卡马克 D 形），iota~0.4。
- HSX：4 周期，准螺旋对称（QHS）bean。
（来源见下方 Sources。）

### 做法
- 预设 JSON 加 `shape` 描述符（`kappa`/`tri`/`bean` 为 [φ=0, 半周期] 对，`rot`=每周期极向旋转圈数）；`a=R0/A`、轴偏移=`delta_h`。
- `section_outlines`：有 `shape` 时走显式边界 `_machine_boundary_outlines`（旋转+塑形截面），否则保留近轴（概念堆 HELIAS/NAE-QA 仍是近轴，本就是近轴设计）。
- 线索净：`ConfigSpec.solve()` 只把白名单 `params` 传给求解器、`validate()` 忽略未知键 → `shape` 只到形状视图，**不进功率账**（iota/Vp/Sw 仍是实测覆写）。
- 截面模型（局部 R-Z 平面，余弦展开 cartoon）：
  `x0=cosθ + bean·cos2θ`（肾形），`y0=κ·sin(θ+tri·sinθ)`（拉长+三角），按 `rot·ψ` 旋转，置于轴。

### before → after
- LHD：三切面相同（重叠成一个）→ 三个不同倾角的旋转椭圆。
- W7-X：近轴针/斑 → bean(φ=0) → 三角形(T/2)，含嵌套面+壁层。

### 测试证据
- 新 `test_stellarator_machine_boundary.py`：四真机各渲染**三个互不相同**、简单（非自交）、尺寸 ~a 的截面；W7-X 有 bean（凹）+ 三角（高拉长）两类；LHD 椭圆旋转（box-elong 摆动 >1.5×）；概念堆仍 near-axis。
- 浏览器内用真实服务端 `shape` 输出渲染确认：W7-X bean→triangle、LHD 旋转椭圆形态正确。
