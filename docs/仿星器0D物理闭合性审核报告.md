# 仿星器 0D 物理闭合性审核报告

日期：2026-06-10  
对象：`polyfusion/configs/stellarator.py`、`polyfusion/configs/base.py`、`polyfusion/scan.py`，对照 `docs/27_仿星器代码说明文档.md`、`docs/12_仿星器0D物理调研.md`、`docs/13_仿星器模型实现报告.md`、`docs/23_仿星器模块验证.md`  
结论级别：物理审稿式问题清单；本报告不修改源码

## 1. 总结结论

仿星器模块是除托卡马克外最接近成熟 0D 系统程序的位形。它没有简单套托卡马克的 q/Ip/Greenwald，而是替换成仿星器更合适的三件事：

```text
外部三维线圈给 rotational transform iota
ISS04 替代 IPB98 约束定标
Sudo density limit 替代 Greenwald
```

当前 v2/R4 还加入了“旋转椭圆 + 场周期数 N_fp + 螺旋轴长度”的几何层，使 `iota_geom` 可以由几何估算；并用 W7-X、LHD、HSX、CFQS 的 `iota` 量级做了锚点。这比早期“仿星器 = 无电流托卡马克”要好很多。

因此，仿星器模块可以作为：

> 仿星器 0D 教学、ISS04/Sudo 约束诊断、HELIAS/W7-X/LHD/HSX/CFQS 量级对照和参数初筛模型。

但它还不能作为真实仿星器反应堆预测工具。真实仿星器性能由完整三维磁谱、neoclassical transport、turbulent transport、island divertor、bootstrap current、coil constraints、alpha confinement 和优化位形决定。当前模型把这些复杂性压缩成 `f_ren`、`iota`、`betaT`、`nbar_o_Sudo` 等少数后验指标。

当前最重要的代码级问题是：`iota=0` 或几何 `iota_geom=0` 时会让 ISS04 预测时间为 0，进而 `H_ISS04 = inf`；`Rw>1` 会产生复数；非法组分仍给结果。这些都需要输入域保护。

## 2. 已经闭合的部分

### 2.1 几何层比普通 0D 更明确

当前模型使用：

```text
a = R0 / A
椭圆截面面积 = pi a^2
L_ax = 螺旋磁轴长度
Vp = pi a^2 L_ax
```

截面为旋转椭圆，场周期数 `N_fp` 是输入。这个几何虽然低阶，但至少让仿星器有了自己的“3D 位形参数”，而不只是托卡马克几何的改名版。

测试中：

- W7-X 模型体积 `29.0 m^3`，接近公开约 `30 m^3`。
- LHD、HSX、CFQS 的 `iota_geom` 量级与公开典型值相符。

### 2.2 rotational transform 的几何估算有交叉验证

代码使用：

```text
iota_geom = (N_fp/2) * (kappa_s - 1)^2 / (kappa_s^2 + 1)
```

`test_stellarator_benchmark.py` 用数值 Floquet 积分交叉验证闭式表达，多个点误差约 <0.1%。同时验证：

- `kappa_s = 1` 时 `iota = 0`。
- `kappa_s -> 1/kappa_s` 不变。
- `iota` 随 `N_fp` 线性增加。

这说明作为“旋转椭圆低阶模型”，数学实现是自洽的。

### 2.3 ISS04 和 Sudo 是合适的 0D 后验约束

代码使用：

```text
tau_ISS04 = 0.134 f_ren a^2.28 R^0.64 P^-0.61 n19^0.54 B^0.84 iota^0.41
H_ISS04 = tauE / tau_ISS04

n_Sudo = 0.25 sqrt(P B / (a^2 R)) * 1e20
nbar_o_Sudo = nbar / n_Sudo
```

这两条是仿星器 0D 模型中合理的选择：ISS04 是国际仿星器数据库定标，Sudo 是仿星器密度极限的经典经验式。

`test_stellarator_benchmark.py` 还用 W7-X 纪录炮做了量级锚：

```text
W7-X record-shot H_ISS04 = 1.11
```

这给模块提供了强于“单调性测试”的外部实验支撑。

### 3.3 边界测试暴露的问题

#### P0/P1：`iota = 0` 导致 `H_ISS04 = inf`

测试：

```python
run_case({"kappa_s": 1.0}, preset="W7-X", config="stellarator")
```

输出摘要：

```text
iota_geom = 0
H_ISS04 = inf
```

物理含义：`kappa_s=1` 的旋转椭圆退化成圆形截面，没有旋转变换。无旋转变换就不是有效仿星器闭合磁面模型。ISS04 中 `iota^0.41` 变成 0，`tau_ISS04=0`，于是 `H=tauE/0=inf`。这不是“约束无限好”，而是模型输入无效。

应要求：

```text
iota_used > 0
```

并且最好设置一个下限，例如 `iota_used >= 0.1` 作为数值和物理保护。

#### P0：非法组分仍给结果

测试：

```python
run_case({"fHe": 0.7, "fimp": 0.4}, preset="W7-X", config="stellarator")
```

输出仍为 OK：

```text
Zeff = 8.0566
Pfus = 4.02e-6 MW
Pheat = 5.00 MW
nbar/n_Sudo = 1.215
```

此时燃料份额 `f12 = -0.1`，物理上无效。它会污染 `ne0`、`Zeff`、`Pbrem`、`betaT` 和 Sudo 裕度。

#### P0：`Rw > 1` 产生复数功率和复数 H

测试：

```python
run_case({"Rw": 1.2}, preset="W7-X", config="stellarator")
```

输出摘要：

```text
Pheat = 1.299 + 6.39e-5 i
Qfus = 3.10e-4 - 1.52e-8 i
H_ISS04 = 0.732 + 2.20e-5 i
```

反射率超出 1 没有物理意义。这个应在输入层直接拦截。

#### P0：负剖面指数可崩溃

测试：

```python
run_case({"Sn": -1}, preset="W7-X", config="stellarator")
```

结果：

```text
ZeroDivisionError: float division by zero
```

`Sn/ST` 用在 `(1-x^2)^S` 和多个分母中，应该限制在非负或至少大于使积分收敛的范围。对当前教学模型，最简单可靠的是：

```text
Sn >= 0
ST >= 0
```

## 4. 关键物理缺口

### 4.1 旋转椭圆只是低阶几何模型

真实仿星器的 `iota`、磁井、有效 ripple、banana/neoclassical transport、island structure 由完整 3D 磁谱决定。当前旋转椭圆模型能解释“场周期数和截面旋转能产生 iota”，但不能替代 VMEC/near-axis optimization。

这意味着：

- `iota_geom` 可做教学和量级锚点。
- 不能用 `kappa_s/N_fp` 直接设计真实 W7-X/HELIAS 线圈。
- 真实优化质量仍被塞进 `f_ren` 或显式 `iota`。

### 4.2 ISS04 是经验数据库回归，不是第一性原理

ISS04 是合适的 0D 定标，但它有已知适用边界：

- 高密度接近 Sudo 时约束可能退化。
- 不同位形存在系统性 renormalization，`f_ren` 不确定。
- 优化 stellarator 和传统 heliotron 的 neoclassical/turbulent transport 差别很大。

因此 `H_ISS04=1` 的含义是“与数据库平均相当”，不是“反应堆必然实现”。

### 4.3 Sudo 密度极限是辐射坍缩经验式

Sudo 比 Greenwald 更适合仿星器，但它仍是经验极限。真实密度极限还受杂质、边界辐射、divertor、加热沉积、粒子补给影响。当前代码只输出 `nbar/n_Sudo`，没有边界辐射和杂质谱。

### 4.4 缺少 neoclassical transport、island divertor 和 bootstrap current

真实仿星器设计必须看：

- neoclassical transport，尤其 1/nu 区和 ripple losses。
- turbulent transport 与 profile stiffness。
- bootstrap current 对岛链和 iota profile 的改变。
- island divertor / helical divertor 功率排出。
- alpha confinement 和 energetic particle losses。
- 线圈可制造性、最小间隙、磁面质量。

这些都不在当前 0D 模型中。

## 6. 修正优先级

### P0：输入域与非有限结果保护

- 校验 `R0 > 0`、`A > 0`、`kappa_s > 0`、`N_fp > 0`、`B0 > 0`、`tauE > 0`。
- 校验 `iota_used > 0`，避免 `H_ISS04 = inf`。
- 校验 `Sn >= 0`、`ST >= 0`。
- 校验 `0 <= f1 <= 1`、`0 <= fHe`、`0 <= fimp`、`fHe + fimp <= 1`、`Zimp > 0`。
- 校验 `0 <= Rw <= 1`。
- 若 `Pheat/Q/H_ISS04/nbar_o_Sudo` 为复数、NaN 或 inf，不得作为有效点。

### P1：后验约束要进入 best region

best-window 至少保留：

```text
Pfus >= 10 MW
Qfus >= 1
nbar_o_Sudo <= 1
betaT <= 0.05
H_ISS04 <= 用户阈值
```

`H_ISS04` 不一定要硬限制为 1，但 UI 应让用户看到它是约束假设激进度。

### P2：若要升级到真实仿星器设计判断

需要：

- VMEC/near-axis 或 pyQSC 级磁面几何。
- Effective ripple / neoclassical loss 模型。
- Bootstrap current 与 iota profile。
- Island divertor 功率处理。
- Alpha confinement。
- 位形优化因子 `f_ren` 的来源说明或数据库。

## 9. 最终判断

仿星器模块的物理闭合程度较高，尤其 ISS04/Sudo 与 W7-X/LHD/HSX 锚点给了它可靠的 0D 诊断基础。它适合做“仿星器相比托卡马克少了电流红线、换成 ISS04/Sudo/iota”的教学模型。

但它仍不是真实 3D stellarator 设计程序。当前应优先修复输入域和非有限结果问题，然后继续保持对 `f_ren`、`iota`、`betaT`、`nbar_o_Sudo` 的诚实解释：这些是后验诊断，不是完整位形优化。

## 10. 物理可靠性再审：能不能用于装置设计？

仿星器模块在五个位形里属于较可靠的一类，但可靠的是“0D 诊断层”，不是“3D 位形设计层”：

```text
ISS04/Sudo 让它适合做仿星器 0D 初筛；
旋转椭圆几何不能替代真实 3D 磁谱；
真实反应堆设计必须接 VMEC/BOOZ_XFORM/NEO/SFINCS/ASCOT 等高阶链条。
```

### 10.1 可靠的部分

- ISS04 和 Sudo 都是仿星器/螺旋装置经验数据库量级的关系，比凭空设 `tauE` 更有物理锚点。
- `H_ISS04 = tauE/tau_ISS04` 的解释是正确的：它不是预测成功，而是说明给定 `tauE` 相对数据库定标需要多少约束品质。
- `nbar_o_Sudo` 作为密度极限诊断比套用 Greenwald 更合理。
- 对 HELIAS/W7-X/LHD/HSX/CFQS 这类锚点做量级检查，是适合 0D 模型的验证方式。

### 10.2 不可靠的设计环节

第一，`iota_rotating_ellipse()` 只是低阶几何估算。真实仿星器性能由三维磁谱决定，包括 effective ripple、磁井、ballooning/Mercier 稳定性、bootstrap current、island chain、error field、coil feasibility 和 divertor 拓扑。一个旋转椭圆不能给出这些信息。

第二，`f_ren` 是把“位形优化质量”压缩成一个乘子。这个乘子很方便，但也很危险：如果随意给高 `f_ren`，就等于把 neoclassical optimization、turbulent transport、磁面质量和工程可制造性全部假设成功。

第三，Sudo 密度极限是经验辐射极限，不是硬墙。真实密度上限受杂质、辐射塌缩、边界补给、island divertor、加热沉积和抽气能力影响。`nbar/Sudo < 1` 不能证明稳态可运行。

第四，alpha confinement 和快粒子轨道没有闭合。仿星器反应堆设计里，alpha 粒子在 3D ripple 中的逃逸和局部热负荷是关键问题，0D 功率账默认 alpha/带电产物沉积过理想。

### 10.3 设计使用等级

| 用途 | 当前可信度 | 说明 |
|---|---:|---|
| 仿星器 0D 教学和量级对照 | 高 | ISS04/Sudo 有数据库锚 |
| 概念初筛和 H 因子要求 | 中-高 | 适合看所需 H_ISS04 是否离谱 |
| 真实 3D 位形性能预测 | 低 | 缺磁谱和输运 |
| HELIAS/W7-X 级工程设计 | 低 | 缺线圈、divertor、alpha、neoclassical |
| 反应堆可行性证明 | 不足 | 需要高阶位形优化链 |

### 10.4 更可靠的仿星器方案

建议把仿星器模块升级为“0D 系统账 + 3D 位形外部接口”：

1. 0D 层保留：功率账、ISS04、Sudo、`H_ISS04`、`betaT`、`nbar/Sudo`，但把这些全部标为后验诊断。
2. 3D 几何层：允许从 VMEC 或等价平衡文件导入 `Vp`、`Sp`、磁轴长度、平均小半径、`iota(r)`、磁井、effective ripple、bootstrap current proxy。
3. 输运层：用 ISS04 作为下限基准，同时接 neoclassical proxy 或 SFINCS/NEO 结果；对优化位形用真实 `f_ren` 来源，而不是自由调参。
4. 约束层：增加 Mercier/ballooning 软约束、island/divertor 约束、alpha loss fraction、局部壁热负荷和 coil distance/curvature 指标。

最低可接受升级：

```text
仿星器设计判断 = 0D 功率账
               + H_ISS04 要求
               + Sudo 裕度
               + 真实 3D iota/ripple/磁井
               + alpha loss 和 divertor/coil 约束
```

如果没有 3D 磁场输入，仿星器模块应该只输出“概念初筛可信度”；如果接入真实 VMEC/优化位形，再把可信度提升到“系统设计前端”。
