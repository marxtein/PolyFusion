本轮完成两件事：

## 2. 为什么选一阶近轴展开作为解析位形

审核报告 §10.4 要求"3D 几何层"。可选的解析表示有三类：

| 方案 | 表现力 | 计算量 | 0D 适配性 |
|---|---|---|---|
| 旋转椭圆闭式（旧） | 低：只有截面旋转贡献 iota，轴挠率被丢弃 | O(1) | 已有 |
| VMEC 边界 Fourier | 高，但 iota 需解全 3D 平衡 | 分钟级、需外部代码 | 过重 |
| **一阶近轴展开（采用）** | 中-高：轴 3D Fourier 曲线 + η̄，σ 方程给出含挠率的自洽 iota、拉长剖面、QA/QH 螺旋数 | 一次 61 点周期 ODE Newton 解，毫秒 | 恰好 |

近轴展开（Garren & Boozer 1991；Landreman, Sengupta & Plunk, JPP 85 (2019) 905850103；工具实现 pyQSC）是现代优化仿星器设计的标准起点——"市面上"的解析位形方法正是它。

## 3. 实现

### 3.1 `polyfusion/nearaxis.py`（新增，约 200 行，仅依赖 numpy）

- 轴曲线：`R(φ)=Σ rc_n cos(n N_fp φ), Z(φ)=Σ zs_n sin(n N_fp φ)`（仿星器对称），曲率/挠率/弧长由解析 Fourier 导数 + Frenet 公式得到。
- Boozer 角网格（真空下 ∝ 弧长）+ 谱微分矩阵。
- σ 方程（真空、I2=0、σ0=0）：
  `dσ/dφ_B + (ι + N_hel·N_fp)(η̄⁴/κ⁴ + 1 + σ²) + 2(η̄²/κ²)·τ·G0/B0 = 0`
  Newton 迭代同时解出周期 σ(φ) 和 on-axis ι。
- 螺旋数 `N_hel`：法向矢量象限计数（QA: 0，QH: ±1）。
- 一阶磁面拉长比剖面 e(φ)、弧长加权平均/最大拉长比。

### 3.2 与 pyQSC 发表值的交叉验证（`tests/test_nearaxis_benchmark.py`）

| 量 | 本实现 | pyQSC/论文参考 | 偏差 |
|---|---|---|---|
| 曲率/挠率 15 点 golden（rc=[1.3,0.3,0.01,-0.001]…） | — | pyQSC 断言 rtol=1e-13 | < 2e-14 |
| r1 §5.1 iota | 0.418306910215 | 0.418306910215178 | < 1e-12 |
| r1 §5.1 最大拉长比 | 2.41371 | 2.41373705531443 | < 2e-3（网格极值 vs Fourier 精化） |
| r1 §5.2 iota | 1.931097255357 | 1.93109725535729 | < 1e-12 |
| r1 §5.2 螺旋数 | −1 | −1 | 精确 |

另验证：尺度不变性（长度×s、η̄/s）、η̄ 符号不变性、网格收敛（nphi=31 已到 1e-9）、平面圆轴退化 iota=0、圆轴长 2πR0。
（注：论文 §5.3 为非仿星器对称位形（zc≠0、σ0=−0.6），超出本对称实现范围，未纳入。）

### 3.3 仿星器 solver v3（`configs/stellarator.py`）

- 新增标量输入 `etabar` [1/m]：`etabar=0` 完全保留旧旋转椭圆模式（W7-X/LHD/HSX/CFQS 锚点与全部旧测试不变）；`etabar≠0` 激活近轴模式，轴取 `rc=[R0, delta_h], zs=[0, −delta_h]`。
- 近轴模式下：`iota_geom`（含挠率贡献，`delta_h` 终于影响 iota）、`L_ax`、拉长剖面加权的 `Sp/Sw`；体积仍为 Pappus `V=πa²L_ax`（一阶磁面截面积守恒 πa²，与原口径自洽）。
- 新输出：`Qfus_raw`、`ignited`、`kappa_eff`、`elong_max`、`helicity`、`etabar` 回显。
- 新预设 **NAE-QA**：Landreman–Sengupta r1 §5.1 位形等比放大到 R0=18 m 的 D-T 概念堆（iota=0.4183 为发表值，尺度不变），运行点 Pfus≈1936 MW、Q≈3.5、H_ISS04≈1.02、βT≈3.4%、n̄/Sudo≈0.75，全部在软约束窗口内。

### 3.4 物理域防护层（审核 Phase 1，全位形）

- `ConfigSpec` 新增 `bounds`（区间校验）与 `cross`（跨参数校验）；通用组分闭合校验（`f1∈[0,1]`、`fHe,fimp≥0`、`fHe+fimp<1`）、`Rw∈[0,1]`、`Sn,ST≥0` 等对五个位形统一生效。
- 位形专属：磁镜 `R_mirror>1`、`f_throat∈[0,0.5]`、`f_alpha∈[0,1]`、`B_expand≥1`；FRC `r_s<r_w`、`f_shape∈[2/3,1]`；偶极 `L_in_fac≥1` 且 `L_in<R_p`；仿星器 `delta_h<R0`、显式 `iota>0`、`kappa_s=1` 无旋转变换直接报错（不再出现 `H_ISS04=inf`）。
- 每个 solver 自带同样的 guard（直接调用也安全），违例抛 `ValueError`，`io.run_case` 捕获为结构化 `errors`。

### 3.5 扫描与状态透明（审核 Phase 2）

- `scan2d()`：逐点 validate + try/except，无效点填 NaN、`valid` 网格标记、`scan_errors` 汇总原因；全网格无效时给出聚合错误。
- `best_region_mask()`：强制排除 `valid=0` 与任何判据字段非有限的点——假可行窗口不可能再出现。
- `ConfigSpec.solve()`：输出统一附 `valid` 标志与 `invalid_fields`；`Qfus=1000` 截断保留但 `Qfus_raw` 与 `ignited` 让点火/过驱动/异常三态可区分。
- `app/server.py`：扫描结果 NaN/inf → JSON `null`（浏览器严格 JSON 不再可能炸）、返回 `n_invalid` 与 `scan_errors`。
- `app/index.html`：η̄ 参数输入、新输出符号显示、扫描后无效点黄条提示；并修复一个独立的 Plotly bug——`n·τ` 级别（~1e18）等值线因 `size:1` 浮点舍入崩溃（`size` 改为随级别量级缩放），磁镜/FRC/偶极的 n·τ 等值线由此恢复可用。

## 5. 诚实边界（保持审核口径）

一阶近轴展开仍是**低阶解析模型**：它给出自洽的 on-axis iota、拉长剖面和 QA/QH 分类，但不含磁剪切剖面、磁井深度的二阶项、有效 ripple、新经典/湍流输运、bootstrap、岛屿 divertor、alpha 约束与线圈工程。审核报告 §10.3 的"设计使用等级"表仍然成立——本升级把"3D 位形几何层"从"无"提到"概念初筛级"，并消除了全部已知 P0 假结果路径，但不改变"不能直接声称真实仿星器反应堆性能"的定位。下一级升级仍是 VMEC/pyQSC r2 级接口与新经典 proxy（审核 P2 清单）。

## 6. 追加（2026-06-11）：截面视图与各位形 P1 红线

### 6.1 仿星器截面视图改为服务端真实轮廓

旧 Shape 页只画固定椭圆。现在 `stellarator.section_outlines()` 在服务端生成 φ=0、T/4、T/2 三个切面轮廓，随 `/api/run` 的 `shape` 字段下发：

- 近轴模式：一阶磁面精确重建 `P(θ) = 轴 + a[X1 n̂ + Y1 b̂]`（X1=η̄cosθ/κ，Y1=(κ/η̄)(σcosθ+sinθ)），拉长比**和倾角沿场周期变化**（σ 倾转），投影到 R-Z 平面显示；NAE-QA 三切面 e = 2.11/2.34/2.32，朝向各异。
- 旋转椭圆模式：三切面随 (N_fp/2)φ 旋转、中心沿螺旋轴移动。
- 测试：legacy 切面 shoelace 面积 = πa²（1e-3）；近轴投影面积 ≈ πa²（<20%，截面平面倾斜所致）；拉长比沿周期可变。

### 6.2 审核 P1 红线进 best window（阈值 UI 可改）

- 托卡马克：`q ≥ 2`、`betaN ≤ 3.5`、`H98 ≤ 1.5` 作为**可选判据**（`ConfigSpec.optional_window`，UI 复选框默认关闭）——默认 best window 保持原版四条（Pfus≥10、Q≥1、n̄/nGw≤1、Pheat≤100），勾选红线后窗口收紧（ITER 默认扫描 12 点 → 全红线 8 点）。
- 仿星器：+`H_ISS04 ≤ 1.5`。
- FRC：+`s_param ≥ 2`（软性动理学有效性提示，le 判据仍故意为空，见 docs/25 §8）。
- 磁镜：新输出 `coll_ratio = λ_ii/(R_mc·L_c)` 碰撞域标签（GDT=0.04 气体动力学域，BEAM=52 Pastukhov 域——两预设域判定正确）。
- 偶极：window 不变（β_in≤1）；验证发现 Dipole-DD 预设在 `tauE=5s` 下 Q≥1 区与 β_in≤1 区**不相交**（需假设 tauE≳30s 才出现窗口）——这是诚实结果，正是审核"偶极 Q 完全由输入 tauE 决定"结论的可视化。
- UI：点火点（`ignited=1`）的 Q 显示为 `∞ ⚡点火`，不再伪装成普通 Q=1000 等值。
