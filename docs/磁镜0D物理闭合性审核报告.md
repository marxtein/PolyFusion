# 磁镜 0D 物理闭合性审核报告

日期：2026-06-10  
对象：`polyfusion/configs/mirror.py`、`polyfusion/configs/base.py`、`polyfusion/scan.py` 及 `docs/24_磁镜代码说明文档.md` 相关说明  
结论级别：物理审稿式问题清单，不包含代码修改

## 1. 总结结论

这套磁镜 0D 模型的主干物理是能跑通的：给定中心室几何、镜比、磁场、密度温度和燃料组分，它可以形成一个自洽的稳态功率账本：

```text
Pheat = Pbrem + Pcycl + Ptrans - Pcharged_fusion
```

其中 `Ptrans` 由磁镜端损约束时间 `tau_c` 给出，`tau_c` 又由 Pastukhov 通道、气体动力学通道和径向通道组合而来。这一点是磁镜和托卡马克 0D 模型的本质差别：托卡马克常把 `tauE` 当经验输入或由定标律给出；磁镜的主要损失是开放磁力线端损，应该从损失锥、双极电势、碰撞散射和径向扩散估算。

但是，这套模型目前只能定义为：

> 热麦克斯韦中心室的 classical 0D scoping model，可用于教学、趋势初筛和参数敏感性观察；不能直接作为真实磁镜反应堆性能预测模型。

原因是它尚未闭合几个决定真实磁镜增益的关键物理：

- 端塞电势不是自洽求解，而是用 `phi_i = Te ln(R_mirror)` 的简化估算。
- 没有 neutral beam injection (NBI)、sloshing ions、快离子非麦克斯韦分布和 Fokker-Planck 端塞物理。
- 没有 DCLC、interchange/flute MHD、trapped-particle modes 等稳定性判据。
- D-T 反应的 alpha 自加热按 `fion * Pfus` 直接扣除，但磁镜中 alpha 可能在沉积前沿损失锥逃逸。
- 端部扩张器、直接能量转换、端部热流摊薄没有进入闭合模型。
- Pastukhov 公式在低势垒区会进入非物理域，当前代码未阻止。

因此，当前最准确的定位是：

```text
能跑通：中心室 0D 能量账 + classical 端损 + 热核反应功率。
不够闭合：端塞、快离子、alpha、稳定性、端部工程。
```

## 2. 已经能闭合的部分

### 2.1 能量账闭合

代码的功率账本在正常预设下数值闭合。以 BEAM 预设为例：

| 量 | 数值 |
|---|---:|
| `Pfus` | 12.421 MW |
| `Pn` | 9.937 MW |
| 带电聚变产物功率 `Pfus - Pn` | 2.484 MW |
| `Pbrem + Pcycl + Ptrans` | 34.321 MW |
| `Pheat` | 31.837 MW |
| `Qfus` | 0.390 |

也就是：

```text
34.321 - 2.484 = 31.837 MW
```

这说明程序内部没有出现明显的能量账漏项或符号错误。

### 2.2 聚变功率与辐射损失的形式合理

磁镜模型复用了托卡马克模块中的反应率内核，使用径向剖面加权：

```text
Phi = fsig * 2 * ∫ (1 - x^2)^(2Sn) <sigma v>(T(x)) x dx
Pfus ∝ n1 n2 Phi Vp
```

这对一个热麦克斯韦 0D 中心室模型是合理的。轫致辐射 `Pbrem` 和回旋辐射 `Pcycl` 也沿用了剖面加权表达式，并将磁镜中抗磁削弱后的中心磁场 `B0` 用于回旋辐射。这些处理适合用于“中心室热等离子体”层面的能量账。

需要注意的是：这只适用于热核反应率。如果实际装置靠 NBI 形成高能快离子，热麦克斯韦反应率就不再足够。

### 2.3 端损通道的物理框架是对的

当前磁镜模型的核心约束时间来自三类通道：

- Pastukhov 端损：低碰撞、强电势屏障下，粒子通过碰撞散射进入损失锥。
- 气体动力学端损：高碰撞区，端损更像沿磁力线流出。
- 径向通道：用离子回旋半径相关的经典径向扩散量级估计。

这套“轴向端损 + 径向损失”的框架和现代磁镜 POPCON/中心室模型方向一致。Realta/Hammir 相关论文也明确将 tandem mirror central cell POPCON 与端塞、输运、加热、平衡等模型耦合，用来筛选中心室工作点。

```text
Ti0 = 5 keV
Te0 = 0.1 keV
R_mirror = 6.4
phi_i = Te0 ln(R_mirror) ≈ 0.186 keV
phi_i / Ti0 ≈ 0.037
```

这不是强电势屏障条件。当前公式被用到了不该直接使用的状态域。代码虽然最后给出正的 `tau_c`，但一个通道时间已经是负数，说明物理域没有闭合。

建议：对 Pastukhov 模型增加适用域判据，例如要求 `phi_i/Ti` 高于某个下限；低势垒区应切换到更保守的端损模型，或直接标记该点 invalid。

## 4. 关键物理问题

### 4.1 端塞电势过简化

当前默认：

```text
phi_i = Te ln(R_mirror)
```

这给出一个合理量级，但它不是完整的 ambipolar/end-plug model。真实磁镜的电势与以下因素相关：

- 端部膨胀区磁场和密度分布。
- 电子热传导抑制。
- 离子/电子损失通量平衡。
- NBI、ECRH、端塞加热。
- 串列镜端塞中的非麦克斯韦分布。

GDT 文献中测到的 on-axis potential drop 约为 `2.6-3.1 Te`，这支持“电势势垒确实存在且量级为数倍 Te”，但不能证明 `Te ln R` 足以用于所有预设。

影响：

- `phi_i` 直接进入 Pastukhov 端损。
- `phi_i` 还进入端损能量 `Ptrans`。
- 若 `phi_i` 偏高，模型会高估约束、低估外部加热。
- 若 `phi_i` 偏低或低到 `phi_i/Ti` 不适用，Pastukhov 公式可进入非物理区。

### 4.2 缺少 NBI 和快离子非麦克斯韦物理

BEAM 类装置的核心不是一个简单热麦克斯韦等离子体，而是 neutral-beam-heated mirror。NBI 会带来：

- 高能快离子尾部分布。
- pitch-angle 分布和 sloshing ions。
- 快离子对 DCLC 稳定性的影响。
- beam-target 反应与热-热反应的差别。
- 加热沉积效率与电荷交换损失。

当前模型用 `reactivity(T)` 表示热麦克斯韦反应率，这会把快离子问题折叠成一个等效温度。这对教学可以，但对 BEAM 级别 Q 判断不够。

影响：

- 可能低估或高估真实聚变功率，取决于快离子分布。
- 无法判断 NBI 加热功率、沉积、损失和直接能量回收。
- 无法复现 BEAM 文献里的真实设计逻辑。

### 4.3 alpha 粒子逃逸没有闭合

当前能量账默认带电聚变产物功率全部成为等离子体自加热：

```text
Pheat = losses - fion * Pfus
```

对 D-T 来说，这相当于假设 3.5 MeV alpha 能量有效沉积在等离子体内。但磁镜是开放磁场构型，alpha 出生能量远高于电势屏障，一部分 alpha 会在充分慢化前进入损失锥逃逸。

近期 alpha-loss 文献明确指出：磁镜反应堆中，捕获 alpha 能量对维持反应很关键；但 alpha 出生能量远高于约束电势，可能有相当部分在把能量传给等离子体前损失。

影响：

- 当前模型可能高估自加热。
- `Pheat` 可能被低估。
- 点火/高 Q 窗口可能被画得过乐观。
- 若考虑直接能量转换，逃逸 alpha 不一定是纯损失，但必须单独建模。

建议：

```text
Pheat = losses - eta_alpha_deposit * fion * Pfus - eta_direct * P_lost_charged
```

其中 `eta_alpha_deposit` 不应默认为 1，而应与镜比、电势、alpha slowing-down、pitch-angle scattering 有关。

### 4.4 DCLC 和 MHD 稳定性缺失

当前模型只有 `beta <= 0.6` 这类软窗口，没有真正的稳定性约束。磁镜真实可行性高度依赖稳定性：

- DCLC：损失锥分布驱动的微观不稳定性。
- AIC/Alfven ion cyclotron 类快离子相关不稳定性。
- interchange/flute MHD：轴对称镜典型风险。
- trapped-particle modes。
- line-tying、vortex stabilization、feedback、minimum-B 或端部稳定器。

PPPL/BEAM 报告中也明确提到：MHD 稳定需要 FLR stabilization、plasma shaping、divertors、vortex/feedback 等机制；microinstability 需要 sloshing ions 和高镜比帮助稳定。

影响：

- 0D 功率账显示可行的点，真实装置可能不稳定。
- 高 beta 带来的抗磁井红利不能无条件使用。
- POPCON best region 必须再叠加稳定性区域，否则会误导。

建议：

- 最低限度增加稳定性警示和硬性 invalid 标记。
- 后续逐步加入 DCLC、interchange、beta/FLR、sloshing ion 相关的经验或半解析判据。

### 4.5 Pastukhov 公式适用域没有保护

GAMMA-10 预设出现 `tau_Past < 0`，这是本报告最明确的代码-物理不一致证据。

当前公式含有：

```text
den = 1 + Ti/(2 phi_i) - (Ti/(2 phi_i))^2
tau_Past ∝ r exp(r) G / den
```

当 `phi_i/Ti` 太小，`den` 可变负，导致 `tau_Past` 负值。约束时间为负没有物理意义。

影响：

- 即使最后 `tau_c` 被其他通道组合成正数，中间物理已经失效。
- 扫描图可能包含公式越界后的假结果。
- 对低 `Te`、高 `Ti`、低镜比的实验型预设尤其危险。

建议：

- 对 `phi_i/Ti` 加适用域检查。
- `tau_Past <= 0` 时不得继续作为有效通道参与 `tau_c`。
- 低势垒区切换为更保守的 end-loss 模型，或标记 invalid。

### 4.6 端部热流工程未闭合

BEAM、GAMMA-10、pB-mirror 的 `P_end_flux` 都达到数百 MW/m^2。当前代码计算了这个量，但没有继续处理：

- 端部磁扩张器把热流摊薄到多大面积。
- 直接能量转换回收多少轴向流出能量。
- 端板材料热负荷是否可承受。
- 中性气体、回流、鞘层和杂质源如何反馈核心等离子体。

影响：

- `P_end_flux` 是磁镜工程成败的核心量之一。
- 如果没有端部扩张和能量回收，中心室 `Q` 即使看起来接近可行，工程上也可能不可行。

建议：

至少加入两个工程因子：

```text
B_expansion = B_throat / B_collector
A_collector = 2 A_throat * B_expansion
P_collector_flux = Ptrans / A_collector
eta_direct_conversion = 可选直接能量转换效率
```

### 4.7 高 beta 被过度乐观使用

代码中：

```text
beta = min(raw_beta, 0.99)
B0 = B_vac sqrt(1 - beta)
R_mc = R_mirror / sqrt(1 - beta)
```

高 beta 会降低中心磁场、增加有效镜比，从而提高约束。这是磁镜抗磁井的真实红利。但当前模型没有稳定性代价，只把 `beta <= 0.6` 作为 best-window 软判据。

影响：

- 高 beta 点可能在功率账上很漂亮，但稳定性未知。
- `raw_beta >= 1` 的点被裁成 `0.99` 后继续计算，会制造人工结果。

建议：

- 输出 `raw_beta`。
- `raw_beta >= 1` 应直接 invalid。
- `raw_beta > beta_soft_limit` 应从 best region 排除，并给明确 warning。

## 5. 与外部文献的对照

### 5.1 Realta/Hammir tandem mirror POPCON

文献：Integrated modelling of equilibrium and transport in axisymmetric magnetic mirror fusion devices  
链接：https://arxiv.org/abs/2411.06644

对照结论：

- 文献确实使用 tandem mirror central cell POPCON 思路。
- 文献中的模型包含 integrated end plug simulation、heating、equilibrium、transport。
- 文献特别强调 end plug 是高保真模型，并处理高度非麦克斯韦端塞物理。
- 当前代码只相当于一个简化中心室 0D 层，不具备文献中端塞模型的完整性。

### 5.2 GDT ambipolar potential

文献：Evaluation of ambipolar potential barrier in the gas dynamic trap by Doppler spectroscopy  
链接：https://arxiv.org/abs/2111.10573

对照结论：

- 文献测得中心轴电势降约 `2.6-3.1 Te`。
- 当前 GDT 预设给出 `phi_i/Te = ln(35) = 3.56`，量级接近。
- 这支持“数倍 Te 的 ambipolar barrier 是合理量级”，但不证明 `Te ln R` 可跨所有装置使用。

### 5.3 BEAM

文献：Prospects for a high-field, compact break-even axisymmetric mirror (BEAM) and applications  
链接：https://www.osti.gov/biblio/2281620

对照结论：

- BEAM 是 neutral-beam-heated simple mirror，目标为 break-even 或 `Q ~ 1` 量级。
- 当前代码 BEAM 预设给 `Q = 0.390`，测试中的 flat BEAM-like 点可到 `Q ≈ 1.125`。
- 数量级不离谱，但模型没有 NBI、快离子、sloshing ions 和直接能量转换，因此不是 BEAM 论文复现。

### 5.4 磁镜综述

文献：The Status of Research Regarding Magnetic Mirrors as a Fusion Neutron Source or Power Plant  
链接：https://www.osti.gov/servlets/purl/945622

对照结论：

- 磁镜历史上最大的问题之一就是稳定性与端损。
- 现代磁镜重新受到关注，靠高场磁体、端部工程、稳定化方案和先进加热来改善。
- 当前代码有端损框架，但稳定性与端部工程仍未闭合。

### 5.5 alpha 粒子损失

文献：Energy Spectrum of Lost Alpha Particles in Magnetic Mirror Confinement  
链接：https://arxiv.org/abs/2412.05890

对照结论：

- 文献明确指出，磁镜反应堆中捕获 alpha 能量对维持反应很关键。
- alpha 出生能量远高于约束电势，可能在沉积前通过 pitch-angle scattering 损失。
- 当前代码默认带电聚变产物功率全部作为自加热，偏乐观。

## 7. 修正优先级

### P0：先让物理域闭合

必须先完成：

- `R_mirror > 1`
- `phi_i > 0`
- `tau_Past > 0`
- `tau_c > 0`
- `0 <= f1 <= 1`
- `0 <= fHe`
- `0 <= fimp`
- `fHe + fimp <= 1`
- `Zimp > 0`
- `Sn >= 0`
- `ST >= 0`
- `0 <= Rw <= 1`
- `lnLambda > 0`
- `raw_beta < 1`

扫描时，非法点应填 `NaN`，并在结果中返回 warnings，而不是让整张 POPCON 崩溃。

### P1：补最小物理警戒线

建议加入：

- `raw_beta > 0.6` 警告或排除 best region。
- `lambda_ii/(R L)` 状态域标签：gas-dynamic / transition / Pastukhov。
- `phi_i/Ti` 状态域标签：Pastukhov formula valid / marginal / invalid。
- `P_end_flux` 工程警告。
- `eta_alpha_deposit` 默认小于等于 1，至少作为显式参数。

### P2：补真实磁镜堆判断所需模块

如果目标从教学/初筛升级到“判断磁镜堆是否可能”，需要增加：

- 自洽端塞电势或经验端塞模型。
- NBI 加热、沉积和电荷交换。
- 快离子 Fokker-Planck 或至少有效快离子分量。
- alpha 慢化、逃逸和直接能量转换。
- DCLC/AIC/MHD 稳定性判据。
- 端部扩张器和热流摊薄模型。

### P3：再谈高可信 Q

只有 P0-P2 完成后，`Qfus` 才适合从“趋势指标”升级为“物理预测指标”。在此之前，`Qfus` 应在 UI 和文档中标注：

```text
热麦克斯韦中心室 0D 估算；不含端塞、快离子、alpha 逃逸和稳定性。
```

## 8. 推荐对外表述

建议文档和 UI 中把磁镜模块描述为：

> 磁镜模块为 classical 0D 中心室功率平衡模型，包含热核聚变功率、辐射损失、Pastukhov/气体动力学/径向端损通道、双极电势量级估算和抗磁井修正。该模型适合教学、趋势扫描和初步参数筛选；目前不包含端塞自洽、NBI 快离子、alpha 逃逸、微观/MHD 稳定性和端部能量转换，因此不应用于直接声称反应堆 Q 或工程可行性。

这句话比较稳：既承认它的价值，也不会过度声称。

## 10. 最终判断

这套磁镜模型值得保留，因为它已经把“磁镜为什么不是托卡马克”的主要 0D 差异表达出来了：端损、双极电势、镜比、抗磁井和开放场线热流。

但它当前还不能支撑“磁镜堆可行/不可行”的结论。它能回答的是：

```text
在一组热麦克斯韦中心室假设下，classical 端损和辐射账本会给出什么趋势？
```

它还不能回答的是：

```text
真实 NBI/端塞/快离子/alpha/稳定性/端部工程都算进去后，这台磁镜能不能达到目标 Q？
```

所以后续开发应先补物理域判据，防止假结果；再补稳定性、alpha 和端塞模型；最后才把 `Qfus` 当作更高可信度的性能指标。

## 11. 物理可靠性再审：能不能用于装置设计？

磁镜模块比“只给 tauE 的模型”更进一步，因为它至少把端损作为主约束写进去了。但它仍然没有达到真实磁镜堆设计级：

```text
当前磁镜模型可以做中心室 classical 0D 趋势判断；
不能预测端塞/NBI/快离子/alpha/稳定性都自洽后的真实 Q；
不能仅凭 Pastukhov 或 GDT 通道闭合就判断磁镜反应堆可行。
```

### 11.1 可靠的部分

- 把开放场线端损、镜比、双极电势和抗磁 beta 放进功率账，是磁镜区别于托卡马克的正确物理方向。
- Pastukhov、gas-dynamic、径向通道并联/串联的框架，适合做 classical 端损趋势扫描。
- `P_end_flux`、`P_coll_flux`、`P_alpha_loss`、`Past_domain` 这类输出，比只给 Q 更接近磁镜真实问题，因为端部热流和 alpha 逃逸确实是关键约束。

### 11.2 不可靠的设计环节

第一，端塞电势没有自洽求解。真实 tandem mirror 或 modern mirror 的约束依赖 plug cell、sloshing ions、ECRH/NBI、电子温度、ambipolar potential 和端部损失锥分布。`phi_i = Te ln R` 或用户给定 `phi_i_over_Te` 不能替代端塞物理。

第二，快离子和非麦克斯韦分布缺失。BEAM、WHAM、GDT、Realta/Hammir 这类路线都强烈依赖 NBI、快离子压力、慢化、pitch-angle scattering、charge exchange 和端部损失。热麦克斯韦中心室会低估或错估这些效应。

第三，稳定性没有闭合。DCLC、firehose/interchange、ballooning、MHD flute、轴对称镜端部稳定化都可能决定运行窗口。当前 `beta` 和 `R_mc` 只是输出，不会排除不稳定点。

第四，alpha 和端部工程还不够。带电产物在开放场线中的沉积、逃逸、直接能量转换、expander/collector 热流、材料限制和中性气体/杂质回流，会决定系统级 Q。当前 `f_alpha` 和 `B_expand` 是好入口，但仍是参数化假设。

### 11.3 设计使用等级

| 用途 | 当前可信度 | 说明 |
|---|---:|---|
| 解释磁镜端损和双极电势 | 中-高 | 主物理方向正确 |
| classical 中心室趋势初筛 | 中 | 适合看镜比/电势/密度趋势 |
| BEAM/GDT/Realta 量级对照 | 中-低 | 需要快离子和端塞细节 |
| 真实磁镜反应堆设计 | 低 | 缺 NBI、稳定性、端部工程 |
| 高 Q 可行性证明 | 不足 | 端塞/alpha/快离子未自洽 |

### 11.4 更可靠的磁镜方案

建议把磁镜模块升级为“中心室 0D + 端塞/快离子/端部工程”的多区模型：

1. 中心室层：保留当前热功率账和 classical 端损，但所有 Pastukhov 结果必须带 `Past_domain` 和 `valid_physics_flag`。
2. 端塞层：加入 plug cell 参数，求解 ambipolar potential，而不是简单设定 `phi_i`。最少也要输出“所需 plug power/Te/phi 是否离谱”。
3. 快离子层：加入 NBI beam energy、injection angle、capture、slowing down、charge exchange、orbit loss、fast-ion pressure fraction，并把热离子和快离子反应率分开。
4. 稳定性层：增加 DCLC、interchange/flute、firehose、beta、loss-cone anisotropy 的红线或 proxy。
5. 端部工程层：把 `P_end_flux`、`P_coll_flux`、alpha loss、direct conversion efficiency、collector area、材料热流阈值放进 POPCON mask。

最低可接受升级：

```text
磁镜设计判断 = 中心室功率账
             + Pastukhov/GDT 适用域
             + 端塞电势/功率自洽
             + NBI/快离子分布
             + alpha 逃逸和端部热流
             + DCLC/MHD 稳定性红线
```

在这些补齐前，磁镜 Q 应解释为“给定端塞/alpha/快离子假设下的中心室热平衡结果”，不能解释为完整磁镜反应堆性能。
