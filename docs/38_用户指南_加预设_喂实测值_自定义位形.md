# 用户指南：加预设 / 喂实测值 / 自定义位形

> 核心：一个位形的全部输入就是一个**参数 dict**。预设、实测覆盖、自定义几何都是"往这个 dict 填值"。三层入口，按需求选。

## 第1层：加预设（最常用）

### A. 浏览器里另存（不碰代码）
1. 选位形 → 调好左栏参数。
2. 点 **★ 另存为预设** → 起个名。
3. 它出现在预设下拉的 **"我的预设 / My presets"** 分组，存在浏览器 localStorage（本机持久）。
4. 选它即加载；选中时 **✕ 删除预设** 可删。
5. 分享：用 **⬇ 保存参数 / ⬆ 加载参数** 导出/导入 JSON 给别人。

### B. 加到内置预设（随程序分发）
预设已是数据文件：`polyfusion/presets/<config>.json`，结构：
```json
{ "presets": { "我的机型": { "R0": 6.0, "A": 3.0, ... } },
  "groups":  { "实验装置 Experiments": ["我的机型"] } }
```
加一段进对应 config 的 JSON 即可，无需改 Python。字段名 = 该位形的输入参数（见 `/api/meta` 或左栏）。

### C. 跨机/团队共享预设
放到用户目录 `~/.polyfusion/presets/<config>.json`（同结构）。loader 会在打包预设之上**合并**它（同名覆盖）。注意：进程启动时加载一次，新增后需重启服务生效。

## 第2层：喂实测值（覆盖模型推导值）

代码用**哨兵覆盖**惯例：某量留 0（或留空）= 模型自己算；给具体值 = 用你的实测/指定值。常用覆盖字段：

| 字段 | 位形 | 0/空 = | 给值 = |
|---|---|---|---|
| `iota` | 仿星器 | 用近轴几何推导 | 实测旋转变换（W7-X 0.88、LHD 0.40…） |
| `Vp_override` | 仿星器 | 用几何算体积 | 实测等离子体体积 [m³] |
| `Sw_override` | 仿星器 | 用几何算壁面积 | 实测壁面积 [m²] |
| `tauE` | 托卡马克/仿星器 | （=0）用定标预测 | 手填能量约束时间 [s] |
| `fT` (Te/Ti) | 托卡马克/仿星器 | （=0）自洽解 Te | 手填温度比 |
| `phi_i_over_Te` | 磁镜 | 自动 Te·lnR | 手填电势比 |

**真机怎么加**：近轴单谐表达不了的真实机器（W7-X 准等动、LHD heliotron），就喂 `iota` + `Vp_override`（+可选 `Sw_override`）——几何只管体积/面积，变换用实测。这就是 W7-X/LHD 预设的做法。

## 第3层：自己设计位形

### 3a. 在已有位形里设计新形状（自定义仿星器轴）
仿星器几何 = 轴傅里叶 `rc`/`zs` + `N_fp` + `etabar`。
- 默认：标量 `delta_h` 给单谐螺旋轴。
- 高级：左栏 **rc / zs** 文本框填逗号分隔的傅里叶系数（如 `rc=18,0.9,0.1`、`zs=0,-0.9,-0.1`）→ 直接喂近轴求解器，设计任意自定义轴。留空则用 `delta_h`。
- `etabar` 是塑形旋钮（拉长比是**输出**，不是输入）。

### 3b. 发明全新位形类型（新物理）
需开发者写新 solver + ConfigSpec 注册（如 Z-pinch）。架构干净：加一个 `ConfigSpec`，UI/扫描不动。非终端用户操作。

## 安全
用户填的预设/覆盖/自定义几何全过同一套校验（`ConfigSpec.validate` + bounds + cross + solver 域保护）。非法点会被拦或标 invalid，开放填值不会破坏物理域保护。

## 边界提醒
- 仿星器一阶近轴截面恒为椭圆，无真机 bean/月牙高阶形变（需二阶近轴，未来阶段）。
- 0D 功率账只吃**体积+拉长比+iota**；磁面形状细节不进账。
