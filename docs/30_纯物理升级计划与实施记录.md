## 总纲：这批升级的共同哲学

现在程序里有一批量是**用户拍脑袋输入的**，但物理上它们应该是**算出来的**：

| 量 | 现状 | 它实际由什么决定 |
|---|---|---|
| fT = Te/Ti | 输入 | 离子-电子碰撞换热 vs 电子辐射损失的平衡 |
| 杂质辐射 | 只算轫致（系统性低估） | 线辐射（束缚电子跃迁），比轫致大可达一个量级 |
| f_alpha（磁镜 α 沉积份额） | 输入 | 损失锥立体角 + 慢化竞争 |
| 点偶极场 | L=1.5 r_ring 处用远场公式 | 载流环的真实场（这里根本不是远场） |
| FRC 磁通寿命 | 没有这本账 | 电阻扩散时间 |
| 仿星器 β 限 / 输运 | 拍脑袋 5% / 纯 ISS04 | 该位形自己的磁阱/Mercier、新经典输运 |

把"输入"变"输出"= 消除物理上的循环论证。这是全批次的主线。

## 第一批（本轮实施）

### P1-1 双温物理基础件：`twotemp.py`

**现状**：程序把 Te 当 Ti 的固定比例（fT 输入）。等于让用户替模型回答"电子有多冷"。

**为什么是问题**：离子和电子是两群温度可以差很远的粒子。聚变发生在离子之间，
但辐射损失（轫致、回旋）全走电子通道。两群粒子之间只靠碰撞换热，而换热很慢
（电子太轻，撞离子像乒乓球撞保龄球，一次只传 me/mi ~ 1/3600 的能量）。
所以"离子热、电子冷"是物理上可能且宝贵的状态（热离子模式）——
p-B11 的可行性论证、磁镜的 Te≪Ti、Helion 的离子加热路线全靠它。
固定 fT 把这整个维度焊死了。

**本批做什么**：先建物理基础件 + 全位形诊断输出（不动功率平衡，golden 不破）；
完整的"Te 自洽求解模式"放第二批（要改每个 solver 的平衡结构，单独做）。

三个函数（`polyfusion/twotemp.py`）：

1. **临界能量** E_crit——快粒子（如 3.5 MeV 的 α）慢化时，能量给离子还是给电子的分水岭：
   ```text
   E_crit = 14.8 · A_fast · Te · [ Σ(n_i Z_i²/A_i)/n_e ]^(2/3)   [keV]
   ```
   直觉：快粒子比电子热运动快得多时，电子拖不住它，能量主要给电子；
   慢下来接近临界能量后开始主要撞给离子。D-T 等离子体 Te=10 keV 时 E_crit≈330 keV，
   而 α 生下来 3500 keV ≫ E_crit——**所以 α 加热主要先加热电子**，这是 fT 应该
   接近 1 甚至 Te>Ti 的根本原因（除非有办法只加热离子）。

2. **Stix 离子沉积份额**——快粒子从出生能量 E0 慢化到 0，平均分给离子的份额：
   ```text
   f_ion(E0/E_crit) = (E_crit/E0) ∫₀^(E0/Ec) du/(1+u^(3/2))
   ```
   极限自检：E0≪Ec → f_ion→1（全给离子）；E0≫Ec → f_ion→0。
   D-T α：f_ion ≈ 0.2（80% 给电子！）——以后做双温平衡时这是关键输入。

3. **离子-电子换热**（NRL 公式手册标准式）：
   ```text
   1/τ_eq ∝ √(m_e m_i) Z² n_i lnΛ / (m_i T_e)^(3/2)
   P_ei = (3/2) n_i (T_i−T_e) e·10³ / τ_eq    [W/m³]
   ```
   锚点：D 等离子体 n=10²⁰、Te=10 keV → τ_eq ≈ 0.36 s（教科书量级）。
   直觉读法：τ_eq 和 τE 同量级时，"离子热电子冷"撑得住；τ_eq ≪ τE 时两温必然拉平。

**新输出（全部五个位形）**：`Ecrit`、`f_fast_ion`（带电聚变产物给离子的份额）、
`tau_eq_ie`、`P_ei`（当前 Ti/Te 下离子流向电子的换热功率）。
这些是诊断量——用户立刻能看到"我假设的 fT 和换热物理矛盾不矛盾"
（例如 fT=0.5 但 τ_eq≪τE 的点：物理上撑不住热离子状态，假设自相矛盾）。

**验证**：极限自检 + τ_eq 教科书锚点 + f_ion 数值积分对解析特例。

### P1-2 杂质线辐射：`impurity.py`（Mavrin 2018 冷却函数）

**现状**：杂质只通过 Zeff 进轫致辐射。

**为什么是问题**：杂质离子没被完全剥光电子时，束缚电子被碰撞激发后跃迁发光
（线辐射），这部分**不在轫致公式里**，且对中高 Z 杂质比轫致大一个量级。
例：氩在 Te=2 keV 时总冷却函数约为其轫致部分的 ~10 倍。
现在的模型对"杂质有多毒"系统性乐观。

**怎么改**：Mavrin (2018, Radiation Effects & Defects in Solids) 给了 11 种元素
（He/Li/Be/C/N/O/Ne/Ar/Kr/Xe/W）的冷却函数分段多项式拟合：
```text
log10 L_z = Σ_k c_k · (log10 Te[keV])^k     （分 Te 区间，0.1–100 keV）
P_imp = n_e · n_imp · L_z(Te)    [W/m³]，沿剖面 2x dx 积分
```
系数表取自本地 cfspopcon 克隆（MIT 协议，引用注明；
注意 cfspopcon 该文件自身变量名有错位，我们按 Mavrin 原文口径实现并独立验证）。

**防双算**：我们的 Pbrem 里已经含杂质的轫致部分（经 Zeff），
所以净新增项 = L_z(总) − L_z(轫致部分估计 5.34e-37·Z²√Te)，截断到 ≥0。

**接口**：新可选输入 `imp_name`（"Ar"/"W"/…，默认 None = 完全旧行为，golden 不破）。
给定时输出 `P_line` 并计入功率平衡。Zimp/组分暂保持用户输入（平均电荷态
⟨Z⟩(Te) 自洽留到第二批）。

**验证（很漂亮的交叉检验）**：He 在高温下是全剥离的，Mavrin 的 He 冷却函数
应该≈纯轫致——和我们自己的轫致常数 5.34e-37 比对（预期 10% 内一致，
两套完全独立的来源互相印证）。另加 W@10 keV ≈ 1.3e-31 W·m³ 文献量级锚。

### P1-3 偶极场有限环修正：`ringfield.py`

**现状**：用点偶极远场 B ∝ 1/L³、场线 r=Lcos²λ、U ∝ L⁴。
但等离子体内边界在 L = 1.5·r_ring——离一个半径为 r_ring 的载流环
只有 1.5 倍半径远，**根本不是远场**。LDX 实际更近。几何误差几十个百分点级。

**怎么改**：载流圆环的场有精确解析解（椭圆积分 K、E，用 AGM 算法 30 行实现，
不引依赖）。更妙的是轴对称真空场有个恒等式省掉所有场线追踪：
```text
磁通函数 ψ(ρ,z) = (μ0 I/2π)·√(aρ)·[(2/k − k)K(k) − (2/k)E(k)]
场线 = ψ 的等值线；磁通管比容 U = dV/dψ （精确恒等式）
```
做法：一次性在无量纲网格（λ=L/a）上算 ψ、对 ψ 等值线求包络体积 V(ψ)、
数值微分得 U——预计算成通用表（环几何无量纲，算一次缓存，永久复用），
solver 查表，速度与点偶极版相同。

**接口**：新输入 `ring_model`（0=点偶极（默认，旧行为），1=有限环）。
剖面逻辑不变（仍是 δ(pU^γ)=0 边际稳定，只是 U(L) 换成真实环的），
体积权重、B(L)、β_in 全部跟着修正。

**验证**：大 λ 极限必须收敛回点偶极的三个解析结果
（B→偶极律、U∝λ⁴、V→64πλ³/105）——这是"修正项做对了"的硬判据；
近区（λ=1.5）给出与点偶极的偏差表，写进文档。

### P1-4 FRC 磁通寿命账：`tau_eta` 输出

**现状**：FRC 有粒子账、能量账、压强账，没有**磁通账**。
但俘获磁通 Φ_p 是 FRC 的命：电阻把它耗散完，位形就解体——
燃烧时间被它封顶，和 τ_N 谁短听谁的。

**怎么改**（量级账，诚实标注）：
```text
Spitzer 电阻率 η ≈ 5.2e-5 · Zeff · lnΛ / Te[eV]^(3/2)   [Ω·m]
经典磁扩散时标 τ_η = μ0 r_s² / η
新输出：tau_eta、tau_N/tau_eta（<1 表示能量先漏，>1 表示磁通先死）
```
明确标注：这是**经典上限**——实验上 FRC 磁通衰减普遍反常（更快），
所以 τ_η 是乐观界，不是预测。但有这本账就能回答"哪本账先破产"。

**验证**：η 对教科书值（Te=100 eV → η≈9e-7 Ω·m）；τ_η ∝ r_s²、∝ Te^1.5 标度。
