# 多位形升级研究笔记 (2026-06-20)

针对 0D 聚变反应堆设计工具的三个问题：剖面形状（仿星器 H 模 / 托卡马克台基）、运行窗口判据（磁镜 / FRC / 偶极）、几何参数教学公式。

---

## Q1 — 仿星器 H 模 / 台基剖面，以及托卡马克台基形状

### 1.1 仿星器确实存在 H 模（实验证据）

- **W7-AS** 是第一台在**非托卡马克**装置上实现 H 模的设备。高功率 140 GHz ECRH 下观察到类 H 模转换：转换后**边缘密度梯度变陡**、极向旋转增强、杂质辐射上升、出现边缘 MHD 活动（ELM）。
- W7-AS 还发现了 **HDH 模（High-Density H-mode，高密度 H 模）**：能量约束达到 H 模水平，而杂质约束停留在 L 模水平（这正是稳态运行想要的——能量约束好、杂质不积累）。HDH 在所有 P > 0.7 MW 的功率及最高 β 值下都能建立。
- **LHD（大型螺旋装置）** 也观察到边缘输运垒 / H 模类转换；W7-X 在高密度下有相关的边缘稳定性 / 脱靶研究。
- **TJ-II** 同样报告了 H 模转换。

### 1.2 仿星器台基与托卡马克的关键差别（重要）

> **仿星器 H 模转换时，主要是边缘*密度*梯度变陡；*温度*剖面几乎不受影响**（除了 W7-AS 充分发展的静默 H 模 quiescent H-mode 例外）。

这与托卡马克不同：托卡马克 H 模在密度**和**温度上都有明显台基。物理上，仿星器旋转变换由外部线圈提供，边缘自举电流 / 边缘电流密度作用弱，台基不像托卡马克那样是压强双台基。

### 1.3 托卡马克台基形状（用于 tanh-台基 + 抛物线芯部模型）

标准做法：电子密度、温度剖面用 **tanh 基函数**拟合（DIII-D 标准，EPED 模型也用修正 tanh）。关键数值：

- **台基宽度 Δ ≈ 极小半径的 3%–5%**，典型不超过 5%–10%（即归一化极向磁通 ψ_N 中 Δ ≈ 0.03–0.05）。
- 台基顶（pedestal top）取在 LCFS 内约 1.0–1.5 Δ 处；"knee（拐点）"处的压强 / 密度即定义台基压强 / 密度。
- 台基顶 vs 芯部：台基顶值约为芯部峰值的 **0.3–0.6**（即芯部相对台基的"峰化因子"约 1.5–3，取决于剖面峰化程度）。

**推荐的剖面模型（适用于工具）**：
```
f(ρ) = f_sep + (f_ped - f_sep) * 0.5*(1 - tanh((ρ - ρ_ped)/(Δ/2)))      # 台基(tanh)
       + (f_0 - f_ped) * (1 - (ρ/ρ_ped)^α)^β   for ρ<ρ_ped              # 抛物线芯部
```
- 台基位置 ρ_ped ≈ 0.94–0.97（即 Δ ≈ 0.03–0.06 a）
- 芯部峰化 α≈2, β≈1（抛物线）至更峰化

### 1.4 给设计工具的具体建议

| 位形 | 是否加 H 模台基 | 台基特征 |
|------|----------------|----------|
| 托卡马克 | **是** | 密度+温度双台基，Δ≈3%–5% a，台基顶/芯峰 ≈ 0.3–0.6 |
| 仿星器 | **有限度地加** | 主要在**密度**上加弱台基（Δ≈3%–5% a），**温度剖面接近无台基**（边缘 T 梯度变化小）。台基"高度分数"应明显弱于托卡马克——建议密度台基顶/芯峰 ≈ 0.5–0.7（更平），温度基本用纯抛物线/无台基 |

即：仿星器**不应**简单复用托卡马克的双台基剖面；推荐"密度弱台基 + 温度无台基"。

## Q2 — 运行窗口 / "最佳区域" 判据评估

### 2.1 磁镜（mirror）

当前判据：Pfus≥1 MW, Qfus≥1, β≤0.6

**评价**：Pfus/Qfus 合理但宽松；β≤0.6 数值基本合理但缺失大量关键物理。

- **β 限制**：实验上 minimum-B 位形（2XII-B）实现了**平均 β ≈ 70%**。镜胞内 β 上限通常取 **0.5–0.7**。所以 **β≤0.6 是合理的中间值**，但应明确这是"镜胞 / 中心胞 β"。可放宽到 0.7（minimum-B 稳定上限），或保守取 0.5。
- **缺失：镜比 R_m 阈值**。R_m = B_max/B_min 决定损失锥、端损失。简单镜 R_m 通常需 ≳ 5–10；高镜比（>10，有限 β 可进一步抬高）显著减少端损失。**建议加 R_m ≥ ~5（简单镜）的下限判据。**
- **缺失：MHD 稳定性类型**。经典轴对称圆镜因中平面不利曲率 MHD **不稳定**；必须用 **minimum-B（磁阱）**或四极场、或壁稳定 / 动理学稳定。建议加"是否 minimum-B / 平均磁阱"的稳定性 gate。
- **缺失：双镜（tandem）的安培极 / Yushmanov-Pastukhov 电势**。端损失由 plug 形成的双极电势控制。Pastukhov（1974）/ Cohen（1978）公式给出约束增强：
  - τ_i ∝ (e Δφ / T_i) · exp(e Δφ / T_i)，即端约束随 **e Δφ/T 指数增强**。
  - 实验观察到中心胞离子约束增强因子可达约 **8×**。
- **缺失：Q 增益上限**。简单镜 Q 受损失锥限制，Q 通常 < 1（这是镜机的历史难题）；双镜可达 **Q ≈ 5–10**（甚至设计目标 Q ≥ 30 需磁镜+静电+有质动力三重约束）。**建议：若位形是简单镜，对 Qfus 设更现实的上限警告（简单镜很难 Q>1）。**

**磁镜建议新增判据**：R_m ≥ 5；minimum-B / 磁阱稳定标志；区分简单镜 vs 双镜的 Q 现实性；β 上限可设 0.6–0.7（标注为镜胞 β）。

### 2.2 FRC（场反位形）

当前判据：Pfus≥1, Qfus≥1, s≥2, 无上限

**评价**：

- **β≈1 是定义**：FRC 体平均 β 几乎为 1，⟨β⟩ = 1 − 0.5·(r_s/r_w)²，典型范围 0.5–1，可达 ~90%。**所以"β 上限"判据毫无意义——确认应去掉任何 β 上限**（当前工具对 FRC 没设 β 上限，是对的）。
- **s（kinetic 参数）= 分离面半径 / 离子回旋半径**（≈ 分离面半径 / 离子集肤深度）。s≥2 下限合理：s 太小则太"动理学"、约束差、不像 MHD 平衡。
- **缺失：最关键的是 s/E 比（倾斜 tilt 稳定性）**。全局 MHD 稳定要求：
  > **s/E ≲ 3–4**（E = 分离面伸长率 = 分离面半长 / 半径）
  - n=1 倾斜不稳定是 FRC 主要威胁；有限拉莫尔半径（FLR）效应、快离子束、Hall 效应可抑制。
  - **建议加判据：s/E ≤ 3–4 作为倾斜稳定上限**。这是 FRC 最重要的缺失项。
- **缺失：n·τ Lawson / 三乘积**。当前只有 Pfus/Qfus，建议显式给出 n·τ_E 或 n·T·τ_E 与点火 / Q 目标的关系。

**FRC 建议新增判据**：**s/E ≤ 3–4（倾斜稳定，最重要）**；去掉 β 上限（β≈1 by definition）；保留 s≥2 下限；加 Lawson n·τ。

### 2.3 偶极（dipole，如悬浮偶极 LDX）

当前判据：Pfus≥1, Qfus≥1, β_in≤1.0

**评价**：β_in≤1.0 意义不大；缺失最核心的对流 / 交换稳定性判据。

- **核心物理：交换（interchange）/MHD 稳定的绝热判据**：
  > **δ(p · δV^γ) ≤ 0**，其中 δV = ∮ dl/B 是磁通管微分体积，γ = 5/3。
  - 等价临界压强梯度：**d ≡ −d ln p / d ln δV < γ = 5/3**。超过即出现大尺度对流元、输运能量。
  - 偶极场 δV = ∮ dl/B ∝ R⁴，所以边缘稳定剖面 p ∝ V^(−γ) ∝ R^(−20/3)。
  - 边缘 marginally stable（η=2/3）时，磁通管交换不净输运能量，T、n 剖面因绝热压缩保持不变 → 这是偶极独特的"自组织峰化剖面"。
- **β 限制**：偶极的 β 在**环（ring）附近可达局域很高甚至 >1**（高 β 是偶极卖点），但稳定性由上面的压强梯度判据控制，**不是简单的 β 阈值**。所以 **β_in≤1.0 几乎没有约束力 / 物理意义不大**。LDX 实验展示了显著且高度峰化的压强，靠 MHD 可压缩性稳定。

**偶极建议新增判据**：把 β_in≤1.0 替换 / 补充为**绝热交换判据 −d ln p / d ln V < 5/3**（这是真正的"好运行区"门槛）；β 应理解为局域（环附近 vs 内部）量，单一上限意义有限。

## Q3 — 几何参数教学公式（UI 小提示用）

### 3.1 磁镜（magnetic mirror）

- **镜比**：`R_m = B_max / B_min`
  - 提示："镜比越大，越多粒子被反射、端损失越小。简单镜常需 R_m ≳ 5–10。"
- **损失锥角**：`sin²θ_lc = B_min / B_max = 1 / R_m`
  - 即 `sin²θ_lc = 1/R_m`。提示："中平面速度方向落在 θ < θ_lc 锥内的粒子会从端部逃逸。"
  - 等价：`v_∥/v_⊥ > √(R_m − 1)` 的粒子在损失锥内。
- **第一绝热不变量（磁矩）**：`μ = m v_⊥² / (2B) = 常数`
  - 提示："磁矩守恒使 v_⊥² ∝ B，粒子沿磁力线运动到强场区时 v_⊥ 增大、v_∥ 减小直至被反射。"
  - 反射条件：粒子在 B_max 处若 `sin²θ_0 ≥ B_min/B_max` 则被约束（θ_0 为中平面俯仰角）。

### 3.2 FRC（场反位形）

- **伸长率**：`E = l_s / (2 r_s)`（分离面半长 / 半径；注意有的定义 E = 半长/半径，工具内统一即可）
  - 提示："E 越大（越细长 prolate）越易倾斜不稳定。"
- **kinetic 参数**：`s ≈ r_s / ρ_i`（分离面半径 / 离子回旋半径 ≈ r_s / 离子集肤深度）
  - 更精确：`s = ∫ (r/ρ_i) dr` 在场零线到分离面之间。提示："s 衡量配置内有多少个离子回旋半径；s 大→更 MHD、约束好；s 小→更动理学。"
- **倾斜稳定参数**：`s/E ≲ 3–4`
  - 提示："s/E 超过 3–4 时 n=1 倾斜不稳定增长，需 FLR / 快离子 / Hall 效应稳定。"
- **体平均 β**：`⟨β⟩ = 1 − 0.5·(r_s/r_w)²`（典型 0.5–1，≈0.9）

### 3.3 偶极（dipole / 悬浮偶极）

- **L 壳层（L-shell）**：`L = r_eq / R_planet`（磁层语境），实验偶极中标定磁力线 / 磁通面 ψ。提示："L 标定磁力线穿越赤道的半径，外层 L 大、场弱、磁通管体积大。"
- **磁通管微分体积**：`δV = ∮ dl/B ∝ R⁴`（偶极场）
- **交换稳定（绝热）判据**：`δ(p · δV^γ) ≤ 0`，γ = 5/3；等价 `−d ln p / d ln δV < 5/3`
  - 提示："只要压强梯度不超过 5/3 这个绝热临界值，交换模稳定；这也给出自组织峰化剖面 p ∝ R^(−20/3)。"
- **绝热不变量**：粒子有三个绝热不变量（回旋 μ、弹跳 J、漂移 Φ=磁通）。提示："偶极靠粒子在闭合磁力线上弹跳 + 绕环漂移约束，无端损失。"
