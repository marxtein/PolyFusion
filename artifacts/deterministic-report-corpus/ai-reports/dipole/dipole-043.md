3. 风险与不确定性

- 最大的不确定性来自约束时间处理：`use_tauE=1.0` 意味着结果依赖固定 `tauE=5.0` 假设。若改用不同 `tauE` 或改为缩放律，自热、功率平衡和 `Qfus` 可能改变。
- POPCON 解读证据不足：虽然存在 `best` 矩阵，但缺少 `nx`、`ny` 和 `x/y` 数组，因此只能确认“当前准则下未找到最佳区”，不能判断工作窗是否狭窄、分裂、贴边，或对 `Ti0`/`n0` 的敏感方向。
- `best` 全 0 不等于“所有扫描点都无效”。这里 `n_invalid=0`，更接近“扫描点都算出来了，但没有点满足当前最佳判据”。因此问题可能来自判据过严、参数范围不合适，或运行点整体距离目标较远，单靠这份 JSON 无法区分。
- 成分设定较理想化：`Zeff=1.0`、`fHe=0.0`、`fimp=0.0` 会弱化杂质和氦灰对辐射与功率平衡的影响。当前结果因此更像特定输入假设下的基线，而不是对成分扰动后的包络判断。
- 当前 JSON 未提供 beta、q、格林瓦尔德比例、Sudo 比例、L-H 阈值比较等边界信息，因此不能对稳定性边界、密度边界或 L-H 相关判据做进一步工程解读。
- 本次 `config_label` 为偶极场，且给出 `ring_model=1`、`cyclotron_model=equatorial_shell_proxy`。这些模型选择会影响场分布与损失分配，但 JSON 未提供替代模型对比，因此模型敏感性仍未展开。
