1. 核心结论

- 本次报告对应 `config=tokamak`、`preset=ITER`。当前运行点 `valid=1.0`，说明该单点计算在模型内部是有效解；但 `ignited=0.0`，表示该点不是点火态。
- 当前运行点给出的主要功率结果为：`Pfus=4931.35 MW`、`Qfus=1.381`、`Pheat=3571.57 MW`、`Pwall=11.56 MW/m^2`。
- 需要把“单个运行点有效”与“扫描是否找到工作窗”分开看：当前运行点有效，只说明这一组输入参数下 0-D 方程收敛并满足内部判据；它不等于 POPCON 扫描已经证明存在清晰、连续的可操作区域。
- 从 `last_scan.best` 可见，扫描结果并非全 0，因此不能写“当前准则下未找到最佳区”；但由于未提供 `x/y` 数组，且 `nx/ny` 缺失，仍应判定为“扫描网格证据不足，不能判断工作窗形状或敏感性趋势”。
- `use_tauE=1.0`，因此结果依赖固定约束时间假设；同时 `geom_model=0.0`，说明这里使用的是较简化的几何模型。

2. 关键指标解读

- 运行点状态：`valid=1.0` 表示该点在当前模型下可计算；`ignited=0.0` 表示等离子体未进入点火平衡，需要外加/总加热参与维持，和 `Pheat=3571.57 MW` 一起看更合适。
- 聚变与能量增益：`Pfus=4931.35 MW` 对应 `Qfus=1.381`，表明聚变输出高于外部驱动功率口径但并不高很多；这里仅能按 JSON 给出的 0-D 口径解读，不能外推装置级性能结论。
- 热损失与辐射：`Pbrem=225.30 MW`、`Pcycl=1954.91 MW`、`P_line=0.0 MW`，当前辐射损失以回旋/同步辐射项为主，轫致辐射次之，线辐射在本次计算中为零。
- 约束时间与经验标度：`tauE_used=2.0 s`，而 `tau_ITPA20=0.253 s`，并给出 `H98=7.063`、`H_ITPA20=7.908`。由于 `use_tauE=1.0`，这些 H 因子本质上是在说明“要达到当前假定的固定约束时间，相对经验标度需要多大提升”，因此结果对固定 `tauE` 假设敏感。
- L-H 阈值相关：`LH_ratio=26.69`、`P_LH=89.07 MW`。这只能解读为“当前功率与所选 L-H 阈值模型的比较结果”，不能据此写成保证进入或维持 H 模。
- 边界与归一化量：`betaN=22.56`、`betaT=0.319`、`betap=8.889`、`q=2.12`、`q95=3.866`、`nbar_o_nGw=1.115`。这些都是边界/运行约束相关观测量，但 JSON 未提供相应判据阈值，因此这里只能报告数值本身及其归一化含义，不能下超限或可运行结论。
- 成分与杂质：`Zeff=1.867`、`fHe=0.04`、`fimp=0.01`、`Zimp=10`。在当前输入下，等离子体成分比较明确，且 `strcase="D-T"`、`fT_used=1.0` 表明计算按 D-T 燃料口径进行。

- POPCON 扫描：`xkey="Ti0"`、`ykey="ni0"`，说明扫描轴是中心离子温度和中心离子密度；`n_invalid=0` 表示扫描中没有被标记为无效的网格点。`best` 矩阵中存在非零元素，所以扫描并非完全没有候选点，但因缺少 `x/y` 数组以及 `nx/ny` 信息，不能判断最佳区对应的实际参数位置、连续性、边界或趋势。

3. 风险与不确定性

- 最大的不确定性来自 `use_tauE=1.0`：本次结果依赖固定 `tauE=2.0 s` 假设，而不是由所选输运/约束标度自洽给出，因此 `Pfus`、`Qfus`、`Pheat`、`LH_ratio` 等对约束时间假设都较敏感。
- `geom_model=0.0` 带来几何简化风险，特别是 `Pwall`、`Sw`、`Vp` 及相关表面积/体积派生量，只适合做 0-D 初筛口径，不宜据此做更细的工程布置判断。
- 当前运行点有效，不代表扫描已经充分证明存在稳定、宽裕或连续的工作窗。虽然 `best` 矩阵有非零元素，但因为缺少 `x/y` 数组且 `nx/ny` 未给出，扫描网格证据不足，不能判断工作窗形状或敏感性趋势。
- `ignited=0.0` 提醒当前点不是点火态，因此对外部加热、功率平衡和约束时间假设的依赖仍然明显。
- `LH_ratio` 只能视为与某个 L-H 阈值模型的比较结果，不能把它解释成已经保证进入或维持 H 模。
- 报告里没有提供电流驱动、分布效应、MHD 稳定边界、偏滤器热负荷、杂质源项动态等更高维证据，因此任何超出 0-D 口径的装置级结论都不确定。

4. 下一步建议

- 建议先做一轮补全型 POPCON 扫描：显式输出 `x`、`y` 数组以及 `nx/ny`，继续以 `Ti0` 和 `ni0` 为轴，并监控 `best`、`n_invalid`、`valid`、`ignited`、`Pfus`、`Qfus`、`Pheat`、`Pwall`，以确认候选区是否连续、是否只出现在少数离散网格点。
- 建议做约束时间敏感性扫描：在保持其他参数不变时，扫描 `tauE` 或切换到 `use_tauE=0` 并比较不同 `tauE_scaling`/经验标度结果，重点监控 `tauE_used`、`H98`、`H_ITPA20`、`Pfus`、`Qfus`、`LH_ratio`、`ignited`。
- 建议做几何口径复核：改变 `geom_model` 或引入 `Sw_override`、`Vp_override` 的对照计算，重点监控 `Sw`、`Vp`、`Pwall`、`Pbrem`、`Pcycl`，判断简化几何对壁负荷和辐射分配的影响。
- 建议做边界量定向扫描：围绕当前点扫描 `Ip`、`BT0`、`R0`、`A` 或密度相关参数，重点监控 `betaN`、`betaT`、`betap`、`q`、`q95`、`nbar_o_nGw`、`Pwall`、`valid`，用于识别哪些输入最直接推动边界相关量变化。
- 建议做成分与辐射敏感性扫描：扫描 `fHe`、`fimp`、`Zimp`，重点监控 `Zeff`、`Pbrem`、`P_line`、`Pcycl`、`Pfus`、`Qfus`、`Pheat`，以分辨当前结果对杂质和灰分假设的依赖。
- 如果目标是评估是否存在“更优单点”，建议以当前点为中心做局部细网格扫描，至少同时记录 `best`、`valid`、`ignited`、`Pfus`、`Qfus`、`Pheat`、`Pwall`、`LH_ratio`、`betaN`、`nbar_o_nGw`，避免只看单一指标。
